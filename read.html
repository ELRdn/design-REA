第三に、歴史は振り子ではなく、螺旋である。 装飾と禁欲、手仕事と工業、個人と大量生産、地方と世界。同じ場所に戻ってくるように見えて、戻ってくるたびに技術と責任の水準が上がっています。だから「昔は良かった」も「今が最高」も、どちらも半分しか正しくありません。

第四に、「デザイナー」という職業は最近の発明だが、デザインは古い。 名もなき職人、女性、植民地にされた人々、使う側の人々が、歴史の大部分を作ってきました。有名デザイナーの列伝は、歴史の一部ではあっても、全体ではありません。

第五に、デザインは「どう生きるか」の提案である。 椅子は座り方の提案であり、スマートフォンは注意の配り方の提案であり、都市は共同体の提案です。デザインは中立ではありません。何を可能にし、何を不可能にするかという形で、政治をしています。

第I部 デザインとは何か

序章 なぜデザインの歴史を学ぶと、世界の見え方が変わるのか

2,226 CHARACTERS約 4 分

ある朝の風景

2026年10月、あなたは目覚まし時計で目を覚ます。スマートフォンを手に取り、通知を確認する。顔を洗い、歯を磨き、服を選び、コーヒーを淹れる。電車に乗り、改札にスマホをかざし、オフィスの椅子に座り、画面を開く。

この朝のあいだに、あなたは何百もの「デザインされたもの」に触れています。目覚まし時計の文字盤、歯ブラシの握りやすさ、シャツの縫い目、コーヒーカップの取っ手、改札機の高さ、椅子の背もたれ、画面のアイコンの並び。どれも、誰かが「こう使ってほしい」と考えて、かたちにしたものです。

デザインの歴史を学ぶというのは、この当たり前の朝を、「誰かの決断の集積」として見直すことです。カップの取っ手が右側にあるのはなぜか。改札機が腰の高さにあるのはなぜか。通知が赤い丸で表示されるのはなぜか。そこには、使いやすさの工夫もあれば、習慣の押しつけもあり、商売の都合もあり、政治の選択もあります。

赤ちゃんでもわかる一言
デザインの歴史とは、「身のまわりの当たり前が、どうやって当たり前になったか」を調べる冒険です。

デザイン史の３つの問い

この本では、すべての時代・地域・対象に対して、次の３つを繰り返し問います。

  1. 誰が、誰のために作ったのか。
    作り手は職人か、工場か、企業か、国家か、共同体か。使い手は王か、市民か、消費者か、患者か、子どもか、高齢者か。そこには、常に権力関係があります。

  2. 何を可能にし、何を不可能にしたのか。
    椅子は「座る」を可能にしますが、「立つ」を邪魔することもあります。スマートフォンは「つながる」を可能にしますが、「一人でいる」を難しくします。デザインは、可能性と同時に、制約を配ります。

  3. そのかたちは、どんな世界観を提案しているのか。
    曲線は有機的で親しみやすい。直線は秩序的で近代的。余白は静けさ。金は富。青は信頼。これらの意味は自然法則ではなく、歴史的に作られた約束事です。デザインは、記号の編集でもあります。

歴史は「選択肢の博物館」である

歴史を学ぶ効用は、知識を増やすことだけではありません。「今のやり方は、唯一の正解ではない」と知ることです。

たとえば、椅子ひとつとっても、古代エジプトの折りたたみ椅子、中国の明式家具、アフリカの腰掛け、北欧の曲木椅子、バウハウスの鋼管椅子、オフィスの人体工学椅子、ゲーミングチェアは、それぞれ「人間の体をどう支えるか」「社会のなかでどう見えるか」についての異なる答えです。今のオフィスチェアが「正しい」のではなく、ある特定の労働環境と身体観に最適化された一つの解にすぎません。

歴史を学ぶと、目の前の対象が「完成品」ではなく「途中経過」に見えてきます。すると、自分で別の解を考える余地が生まれます。これが、デザイン史のいちばん実用的な効用です。

一歩深く（専門家向け）
デザイン史は、大きく三つの方法論に分かれてきました。①「英雄と名作」の美術史型（モリス、グロピウス、ラムズなどの系譜）、②「生産と消費」の社会史型（労働、資本、市場、帝国を重視）、③「物質文化」の文化研究型（モノの意味、使い方、記号、日常生活を重視）。1970年代以降のデザイン史は、①から②③へ重心を移し、さらに1990年代以降はグローバル化・ポストコロニアル・フェミニスト・環境史の影響を受けています。本書は、この三つを意図的に混ぜています。

５つの関係と、螺旋のリズム

本書の背骨は、次の５つの関係です。

  1. 作り手と使い手：職人と顧客、企業と消費者、国家と市民、開発者とユーザー。
  2. 形と機能：美しさと使いやすさ、装飾と構造、意味と性能。
  3. 個人とシステム：一品制作と大量生産、職人の技と標準化、作者とブランド。
  4. 人間と環境：素材、エネルギー、廃棄、修理、再生。
  5. 意味と仕組み：記号、物語、ブランド、インターフェース、アルゴリズム。

そして、歴史は次のようなリズムで動いてきました。

  • 装飾の時代 → 禁欲の時代 → 装飾の復権 → 新しい禁欲 …
  • 手仕事の時代 → 機械の時代 → 手仕事の再評価 → デジタル工作の時代 …
  • 共同体の時代 → 大量生産の時代 → 個別化の時代 → パーソナライズの時代 …

これは単純な振り子ではありません。戻ってくるたびに、技術の水準と責任の範囲が変わります。たとえば「装飾の復権」といっても、19世紀のアーツ・アンド・クラフツ運動と、1980年代のメンフィスと、2020年代のAI生成装飾は、同じ「装飾」でもまったく別のものです。だから本書では、これを「螺旋（らせん）」と呼びます。

この本の読み方

難しい話が出てきたら、まず「赤ちゃんでもわかる一言」を読んでください。それで全体の意味がつかめたら、本文に戻ります。もっと深く知りたくなったら「一歩深く」を読みます。各章の最後には「歴史の教訓」があります。それだけ拾っても、物語の背骨は通ります。

第1章 「デザイン」という言葉の迷宮

3,931 CHARACTERS約 8 分

言葉の旅

「デザイン」という言葉は、ラテン語の designare（デーシグナーレ）にさかのぼります。意味は「印をつける」「示す」「計画する」。そこからイタリア語の disegno（ディゼーニョ）が生まれ、「描くこと」と「心に思い描くこと」の両方を意味するようになりました。フランス語の dessein は「意図」「計画」です。

英語の design は、16世紀には「計画する」「企てる」という意味で使われ、18世紀には「図面に表す」、19世紀には「工業製品の意匠」という現在の意味に近づきます。日本語の「デザイン」は、明治以降に欧米語から入った外来語です。それ以前の日本には「意匠」「図案」「工夫」「細工」といった言葉がありましたが、これらは「デザイン」と完全には重なりません。

ここに、最初の罠があります。「デザイン」という言葉は、ヨーロッパの近代の産物であり、すべての文化に同じ意味で存在するわけではないのです。イスラームの幾何学模様、中国の陶磁器、アフリカの布、先住アメリカの結縄を「デザイン」と呼ぶとき、私たちは近代ヨーロッパの分類を、少し無理やり当てはめています。本書はそのことを忘れずに進みます。

定義のカタログ

「デザインとは何か」に、唯一の正解はありません。代表的な定義を、要約して並べてみましょう（逐語訳ではありません）。

  • ICSID（現WDO）2015年：「工業デザインとは、革新的な製品・システム・サービス・体験を通じて、イノベーションを駆動し、ビジネスの成功を築き、生活の質の向上に貢献する、戦略的な問題解決プロセスである。」
  • V&A（ヴィクトリア・アンド・アルバート博物館）：「デザインとは、特定の目的のために作られた、あらゆるもののことである。」
  • ディーター・ラムズ：「良いデザインは、できるだけ少ないデザインである（Less, but better）。」
  • ヴィクター・パパネック：「デザインは、人間が自分の道具と環境（ひいては社会と自分自身）を形づくる、最も強力な道具である。」
  • ジョン・ヘスケット：「デザインとは、人間の必要性と意味を、人工物の形に変換することである。」
  • ハーバート・サイモン：「デザインとは、現状をより好ましい状態に変えるための行動の計画である。」
  • リチャード・ブキャナン：「デザインとは、問題を発見し、枠組みを与え、解決策を提案するための、独自の思考様式である。」

これらの定義に共通するのは、「意図」「制約」「他者」「かたち」の４つです。デザインは、ただの自己表現ではありません。誰かの意図があり、材料・技術・予算・法律・文化という制約があり、使う他者がいて、その結果としてかたちが生まれます。

赤ちゃんでもわかる一言
デザインとは、「こうしたい」という気持ちを、「こう使える」という形に変えることです。

デザインと芸術は、どこが違うのか

デザインと芸術は、しばしば対比されます。芸術は「問いを立てる」、デザインは「問題を解く」と言われます。しかし、これは単純すぎます。

  • 芸術も、素材・技術・制度・市場という制約のなかで作られます。
  • デザインも、意味や物語を生み出し、問いを立てます。
  • 境界は時代によって動きます。デュシャンの便器は芸術ですが、同じ便器はデザインでもあります。バウハウスの椅子は日用品であり、美術館の収蔵品でもあります。

違いをあえて言うなら、デザインは「使用」を前提にしているということです。使われること、機能すること、誰かの生活に入り込むことを前提に、かたちが決まります。もちろん、使われないことを目的にした「批判的デザイン」もありますが、それも「使用」という制度を問い直すためのデザインです。

デザインと工芸は、どこが違うのか

工芸は、作り手が材料と向き合いながら、作りながら形を決めます。近代の分業モデルでは、デザインは作り始める前に形を決め、図面や仕様として他者に伝えます。この「構想と実行の分離」が、デザインを職業にした決定的な特徴です。

ただし、この分離は近代の産物です。中世の職人は、注文を受けて、材料を見て、作りながら形を決めていました。産業革命以降、工場の所有者・設計者・労働者が分かれ、設計図を描く人と、それを作る人が分かれました。ここに「デザイナー」という職業が生まれます。

一歩深く（専門家向け）
構想と実行の分離は、単なる分業ではなく、知識と権力の再配分です。設計図を描く人が「設計者」になり、作る人が「労働者」になると、設計の知識は現場から経営へ移ります。このことは、テイラリズム（科学的管理法）や、現代の「デザインシステム」にも通じます。誰が決定権を持ち、誰が手を動かすのか。デザイン史は、労働史でもあるのです。

デザインと工学は、どこが違うのか

工学は、物理法則と安全性を中心に、構造・材料・エネルギーを扱います。デザインは、使いやすさ・意味・美しさ・文化を中心に、人と物の関係を扱います。もちろん重なります。自動車の設計には、両方が必要です。

重要なのは、デザインは「性能」だけでなく「意味」を扱うということです。同じ性能の車でも、角ばった車と丸い車では、買う人の感じ方が違います。同じボタンでも、赤いボタンと青いボタンでは、押す人の心理が違います。デザインは、性能を意味に翻訳する仕事です。

「ユーザー」は発明された

「ユーザー中心設計」という言葉を聞くと、当たり前に聞こえます。しかし「ユーザー」という概念は、歴史的に作られたものです。

19世紀の工場では、労働者は「手」でした。20世紀の広告では、人は「消費者」でした。20世紀後半のソフトウェアでは、人は「ユーザー」になりました。21世紀のプラットフォームでは、人は「データ」にもなりました。呼び方が変わると、設計の目的も変わります。

一歩深く（専門家向け）
科学技術社会論（STS）では、技術の設計が「ユーザー」の行動をあらかじめ想定し、方向づけることを 「スクリプト（script）」 と呼びます。たとえば、改札機は「切符を入れる」「ICカードをかざす」という行為を想定し、それ以外の使い方を困難にします。マデリン・アクリッチはこれを「技術の台本」と呼び、スティーブ・ウールガーは「ユーザーの構成（configuring the user）」と呼びました。デザインは、ユーザーを「発見」するだけでなく、「作って」いるのです。

デザインの４つの層

現代のデザインは、４つの層で考えると整理しやすくなります。

  1. モノ（object）：椅子、スマホ、ポスター、建物。
  2. システム（system）：交通網、サプライチェーン、デザインシステム、制度。
  3. サービス（service）：病院の受付、銀行のアプリ、行政の手続き。
  4. 体験（experience）：使う前・使う間・使った後の感情と記憶。

さらに、これらを包む環境（environment）と組織（organization）があります。良いデザイナーは、モノだけを見ません。モノが置かれる場、使う人の時間、支える組織、廃棄された後のことまで見ます。

「良いデザイン」は主張である

「良いデザイン」という言葉は、万能ではありません。誰にとって良いのか、何の基準で良いのかによって、答えは変わります。

  • 機能：目的を果たせるか。
  • 使いやすさ：迷わず使えるか。身体的・認知的な負担は大きくないか。
  • 美しさ：感覚的に心地よいか。意味のある形か。
  • 持続性：長く使えるか。修理できるか。環境負荷は小さいか。
  • 包摂性：多様な身体・能力・文化の人に使えるか。
  • 正義：誰かを排除したり、搾取したりしていないか。

これらは、しばしば衝突します。安くて使いやすい製品が、環境を破壊することがあります。美しい建物が、地域の人を排除することがあります。だからデザインの評価には、トレードオフを明示することが必要です。「すべての人に良いデザイン」は、魔法の言葉ではありません。誰にとっての良さなのかを、具体的に問う言葉です。

デザイン史は、なぜ美術史と違うのか

美術史は、しばしば「名作」と「作者」を中心に組み立てられます。デザイン史は、それだけでは足りません。なぜなら、デザインの大部分は、名もなき職人、工場労働者、女性、植民地の人々、使う人々によって作られてきたからです。

デザイン史は、次のような問いを重視します。

  • 誰が作ったか（作者だけでなく、労働者・職人・共同体も）。
  • 誰のために作ったか（王・市民・消費者・患者・子ども・高齢者）。
  • どう作ったか（素材・技術・分業・エネルギー）。
  • どう使われたか（使用・誤用・修理・再利用）。
  • どう意味づけられたか（広告・展示・批評・博物館）。
  • 誰が排除されたか（女性・障がい者・低所得者・植民地の人々）。

この問いのリストは、この本全体で使い回します。対象を読むときにも使えます（第11章）。

歴史の教訓

歴史の教訓
デザインは「美しいものを作ること」ではない。
「誰が、誰のために、何を可能にし、何を不可能にするか」を、かたちで決めることである。
だからデザインを学ぶことは、権力と責任を学ぶことでもある。

第2章 ５万年前のデザイン ― 道具・土器・文字・都市

4,737 CHARACTERS約 9 分

PLATES IN THIS CHAPTERPL.01 握斧 PL.02 土器

デザインは人間より古い

デザインの歴史は、人類の歴史より長い。人類が現れる前から、私たちの祖先は道具を作っていました。

  • 約260万年前、東アフリカでオルドワン石器が作られます。石を打ち欠いて、鋭い刃を作る、最も初期の道具です。
  • 約176万年前、アシューリアン石器（握斧）が登場します。左右対称の涙形をした石器で、手に握りやすい形をしています。
  • 約30万年前、ホモ・サピエンスが登場します。
  • 約7万年前、南アフリカのブロンボス洞窟で、赤土に幾何学模様を刻んだ石片が作られます。装飾の始まりとされることがあります。
  • 約4万5000年前、インドネシア・スラウェシ島に洞窟壁画が描かれます。
  • 約2万年前、中国・仙人洞で、世界最古級の土器が作られます。
  • 約1万年前、農耕が始まります。
  • 約5000年前、メソポタミアで文字が生まれます。

ここで大切なのは、デザインは「美しいものを作る」ために始まったのではないということです。まず「生き延びる」ために始まりました。切る、掘る、運ぶ、包む、貯める、着る、住む。これらの行為を支えるために、形が工夫されました。

赤ちゃんでもわかる一言
デザインの始まりは、おしゃれではなく、サバイバルでした。石を握りやすく削ることが、最初のデザインです。

握斧は「最初のデザイン」か

アシューリアン握斧は、しばしば「最初のデザイン」として語られます。左右対称で、手に馴染み、切る・掘る・叩くのに使えます。しかし、研究者のあいだでは議論があります。

  • 機能説：握斧は、狩猟・解体・木工に使う実用的な道具である。
  • 性選択説：握斧の美しい対称性は、健康さや認知能力のアピールであり、配偶者選択のための「見せかけ」である。
  • 社会学習説：握斧の形は、集団の伝統を示す「スタイル」であり、仲間意識の指標である。

どれが正しいかは、まだ決着していません。重要なのは、「機能」と「意味」は、最初から分かれていなかったということです。道具は、使うためだけのものではなく、見せるため、誇るため、仲間を示すためのものでもありました。デザインの歴史は、この二つが絡み合う歴史です。

一歩深く（専門家向け）
握斧の対称性をめぐる議論は、進化人類学における「デザインの起源」問題の縮図です。機能主義（適応）と、シグナリング（信号）と、ニッチ構築（環境改変）のどれを重視するかで、説明が変わります。近年は、握斧の形が地域ごとに異なる「文化変異」を示すという研究もあり、単純な機能説では説明しきれません。デザインは、生物学的進化と文化的進化の交差点にあります。

容器の発明 ― 世界を「持ち運ぶ」

デザイン史における最大の発明の一つは、容器です。容器がなければ、食べ物を貯められず、水を運べず、種を保存できず、香料や油を持ち歩けません。

初期の容器は、ひょうたん、木の皮、編みかご、動物の皮袋でした。やがて、粘土を焼いて作る土器が登場します。土器は、人類が初めて作った合成素材の一つです。石や木は自然に存在しますが、粘土を成形し、火で焼いて硬くする土器は、人間が化学変化を利用して作った最初の材料の一つです。

土器の設計には、すでに高度な知識が必要です。

  • 粘土の性質：粘り気、収縮、不純物。
  • 成形：手びねり、紐づくり、ろくろ。
  • 焼成：温度、時間、酸素の量。
  • 形：口の広さ、底の安定性、取っ手の位置、注ぎ口の角度。
  • 装飾：縄目、彩色、彫刻、釉薬。

縄文土器（日本、約1万4000年前）は、縄を押しつけた模様で知られます。装飾的にも見えますが、縄目は粘土の結合を強め、熱伝導を調整する機能もあったと考えられています。装飾と機能は、ここでも分けられません。

赤ちゃんでもわかる一言
土器は「入れ物」ですが、ただの入れ物ではありません。食べ物を守り、水を運び、火を通し、家族の記憶を刻む、最初の「家庭のデザイン」です。

織物 ― 最初の「柔らかいインターフェース」

衣服は、人間が自分の体を包むための、最初の「インターフェース」です。織物は、植物繊維・羊毛・絹・綿を撚り、織り、編み、染める技術です。

  • 約3万6000年前、ジョージアの洞窟で、染色された麻繊維が見つかっています。
  • 約7000年前、トルコのチャタル・ヒュユクで、織物の断片が見つかっています。
  • 約5000年前、中国で絹の養蚕が始まります。
  • 約5000年前、インダス文明で綿が栽培されます。

織物は、単なる保温の道具ではありません。社会的身分、性別、職業、宗教、地域を示す記号でもあります。古代エジプトのリネン、中国の絹、ペルーのアルパカ、アフリカのケンテ、日本の着物。どれも、素材と技法と模様に、その社会の価値観が刻まれています。

織物はまた、最初の「ソフトウェア」でもあります。糸の配置、色の順序、模様の繰り返しは、プログラムのように設計されます。ジャカード織機（1804年）がパンチカードで模様を制御し、その技術が初期のコンピュータに影響を与えたことは、この連続性の象徴です。

文字 ― 記憶を外部化するインターフェース

文字は、デザイン史のもう一つの転換点です。口承だけでは、記憶は時間とともに失われます。文字は、記憶を外部の媒体に保存し、遠くの人に伝え、世代を超えて残すことを可能にしました。

文字の起源は、メソポタミアのトークン（約8000年前）にさかのぼります。羊や穀物の数を表す小さな粘土の印です。やがて、印を粘土の袋（ブッラ）に入れ、袋の表面に印を押すようになります。これがプロト・クネイフォルム（約3300年前）になり、楔形文字（約3200年前）になります。

  • エジプト象形文字：約3200年前。
  • 中国の甲骨文字：約3200年前（商代）。
  • マヤ文字：紀元前3世紀〜紀元後3世紀ごろ。
  • フェニキア文字：約3000年前。アルファベットの原型。
  • 紙：中国で紀元105年ごろ、蔡倫が製紙法を改良。
  • 木版印刷：中国で7〜8世紀ごろ。
  • 活字印刷：中国で1040年ごろ、畢昇（ひつしょう）が陶製活字を発明。朝鮮では13世紀に金属活字。ヨーロッパでは1440年ごろ、グーテンベルクが活版印刷を実用化。

文字は、単なる記録技術ではありません。文字の形そのものがデザインです。楔形文字のくさび形、エジプトの象形、中国の漢字、アラビアの書道、ヨーロッパのアルファベット。それぞれの筆記具、素材、方向、リズムが、文字の形を決めました。書体は、文化の顔です。

一歩深く（専門家向け）
文字の歴史は、「技術決定論」と「文化相対主義」のあいだで揺れてきました。文字があるから国家が生まれるのか、国家があるから文字が必要になるのか。メソポタミアでは、会計と行政の必要が文字を生みました。中国では、占いと祭祀が甲骨文字を生みました。マヤでは、暦と王権が文字を生みました。文字の起源は一つではなく、複数の動機が重なっています。

都市 ― 最初の「デザインシステム」

都市は、デザイン史における最大の人工物です。道路、水路、広場、市場、神殿、城壁、住宅。これらが組み合わさって、一つのシステムを作ります。

  • ウルク（メソポタミア、紀元前4000〜3100年ごろ）：世界最古級の都市。神殿、市場、工房、運河。
  • モヘンジョ・ダロ（インダス文明、紀元前2500年ごろ）：格子状の街路、下水道、公共浴場。古代としては驚くほど計画的な都市。
  • ギザの大ピラミッド（エジプト、紀元前2560年ごろ）：巨大な石造建築。測量、運搬、労働組織の設計。
  • ローマ：道路、水道橋、公共浴場、コロッセオ。紀元前312年のアッピア街道、紀元前312年の水道。
  • 長安（中国、唐時代）：方格状の都市計画。東西の市場、坊制。
  • テオティワカン（メキシコ、紀元前100年〜紀元後550年ごろ）：太陽のピラミッド、死者の大通り。計画都市。

都市は、標準化の産物でもあります。レンガの大きさ、道路の幅、通貨の単位、度量衡、税の単位。これらが揃うことで、遠くの人と取引でき、大規模な建設ができます。秦の始皇帝（紀元前221年）は、度量衡・文字・通貨・車輪の幅を統一しました。これは、国家による最初の「デザインシステム」の一つです。

赤ちゃんでもわかる一言
都市は、たくさんの人が一緒に暮らすための「巨大なルールブック」です。道路の幅も、家の並びも、水の流れも、誰かが決めています。

標準化 ― 見えないデザイン

私たちは、標準化されたものに囲まれています。ネジの規格、紙のサイズ、電源プラグの形、文字コード、道路の左側通行。これらは、目立たないけれど、社会を支える見えないデザインです。

標準化の歴史は古いです。

  • 古代ローマのローマンフット（約29.6cm）。
  • 中国古代の尺や斤。
  • 中世ヨーロッパのギルドによる品質規格。
  • 1799年のフランスのメートル法。
  • 1875年のメートル条約。
  • 1947年のISO（国際標準化機構）。
  • 1980年代以降のHTML、USB、Wi-Fi、QRコード。

標準化は、互換性と効率をもたらしますが、多様性を削り、地域の知恵を排除することもあります。どの規格を選ぶかは、技術の問題であると同時に、政治の問題です。

最初のブランドとサイン

ブランドは、現代だけのものではありません。古代の陶工は、自分の作品に印を刻みました。ローマのレンガには、製造者のスタンプが押されました。中世のギルドは、品質を保証するためにマークを使いました。中国の陶磁器には、皇帝の年号が記されました。

これらは、「誰が作ったか」「どこで作ったか」「どの品質か」を示す、初期のブランドです。ブランドは、信頼を可視化するデザインです。同時に、模倣を防ぎ、市場を支配するための装置でもありました。

そして、社会を調整することだった。
この三つは、今も変わっていない。
どんなに技術が進んでも、デザインは「生存」「意味」「調整」の三つを扱う。

第3章 西洋の外のデザイン ― イスラーム・中国・インド・アフリカ・アメリカ・オセアニア

「歴史なきデザイン」という偏見

19世紀のヨーロッパは、世界を「歴史のある文明」と「歴史のない野蛮」に分けました。博物館は、アフリカやオセアニアの品を「民族誌資料」として展示し、ヨーロッパの品を「美術」として展示しました。この分類は、デザイン史にも深く染み込んでいます。

しかし、イスラームの幾何学模様、中国の陶磁器、インドの布、アフリカの織物、先住アメリカの結縄、オセアニアの航海術は、いずれも高度な設計思想と技術を持っています。それらを「工芸」や「民俗」と呼んでデザイン史の外に置くことは、歴史の書き方の失敗です。

この章では、西洋の外のデザインを、飾りとしてではなく、別の合理性として見ていきます。

赤ちゃんでもわかる一言
世界には、ヨーロッパとは違う「かたちの知恵」がたくさんあります。それは未熟なデザインではなく、別の目的に合わせた、別の完成形です。

3-1 イスラーム ― 無限を描く幾何学

何を作ったのか

イスラーム世界は、7世紀から急速に広がり、ダマスカス、バグダッド（762年建設）、コルドバ、カイロ、イスファハン、イスタンブールなどの都市を生みました。そこでは、モスク、宮殿、庭園、市場、浴場、書物、織物、陶器、金属器が作られました。

幾何学というデザイン言語

イスラームのデザインで最も有名なのは、幾何学模様です。円と四角を重ね、線を交差させ、無限に続くパターンを作ります。ギリーフ・タイル、ゼッリージュ（モロッコのタイル）、ムカルナス（鍾乳石状の穹窿装飾）、アラベスク（植物唐草）などが代表的です。

なぜ幾何学なのでしょうか。

  • 宗教的な理由：多くのイスラーム法学者は、神や預言者の像を作ることを避けました。ただし、これは絶対ではなく、世俗的な場面では人物画も描かれました。ミニアチュール（細密画）はその例です。
  • 数学的な理由：幾何学は、神の創造の秩序を表すと考えられました。無限のパターンは、神の無限性の象徴です。
  • 社会的な理由：幾何学は、職人と学者が共有できる普遍的な言語でした。数学者と職人が協力して、複雑なタイルを設計しました。

一歩深く（専門家向け）
2010年代の研究では、イスラームの幾何学模様が、コンパスと定規だけで描ける「ギリーフ・タイル」の集合から生成されていることが示されました。これは、職人が高度な数学的知識を実践していたことを示唆します。ただし、すべての模様が同じ方法で作られたわけではなく、地域・時代によって技法は多様です。「イスラーム模様＝数学」という単純化は避けるべきですが、数学と工芸の密接な関係は確かです。

建築と都市

イスラーム建築の特徴は、内部空間と水と光です。

  • モスク：礼拝の方向（キブラ）を示すミフラーブ、説教壇（ミンバル）、ミナレット、ドーム。サーマッラーの大モスク（9世紀）の螺旋ミナレット、コルドバの大モスク（8〜10世紀）の列柱ホール、イスファハンのシャー・モスク（17世紀）のドーム。
  • ムカルナス：11世紀半ばごろから発展した、三次元の装飾穹窿。構造と装飾の境界を溶かします。
  • 庭園：チャハール・バーグ（四分割庭園）。水の軸、通路、樹木、壁。砂漠のなかに楽園を作る設計です。
  • 都市：モスク、市場（バザール）、浴場（ハンマーム）、キャラバンサライ、宮殿。日陰と風を確保する路地、屋上の風取り（バードギール）、地下水路（カナート）。

イスラームの都市は、ヨーロッパの「広場中心」とは違い、路地と中庭のネットワークでできています。これは、プライバシー、共同体、気候への適応の設計です。

書物と書道

イスラームでは、書道が最高の芸術の一つとされました。クーフィー体（角張った古い書体）、ナスフ体（読みやすい標準書体）、スルス体（装飾的な書体）、ディーワーニー体（宮廷書体）などがあります。コーランは、書かれ、装飾され、暗誦されるメディアでした。

紙は、751年のタラス川の戦いの後、中国からイスラーム世界に伝わったとされます。バグダッドの「知恵の館」（9世紀）では、ギリシア・インド・ペルシアの書物が翻訳され、製本・照明・書道の技術が発展しました。書物は、宗教と科学と詩を運ぶ、デザインの媒体でした。

オスマン・サファヴィー・ムガル
  • オスマン：イズニク陶器（15〜17世紀）、タイル、ドーム建築。スレイマン・モスク（1550年代、ミマール・スィナン）は、巨大なドームと光の設計で知られます。
  • サファヴィー：イスファハンの王の広場（17世紀）、絨毯、ミニアチュール。都市計画と庭園の融合。
  • ムガル：タージ・マハル（1632〜1653年）、ジャーリー（透かし彫りの石スクリーン）、チャハール・バーグ、細密画。ペルシア・インド・中央アジアの融合。
誤解を解く
  • 「イスラームは像を禁止した」：一概に言えません。宗教的な偶像崇拝は避けられましたが、世俗的な人物画や動物画は多く存在します。
  • 「幾何学は装飾だけ」：幾何学は、数学、宗教、政治、職人技術が交差する、総合的なデザイン言語です。
  • 「イスラーム建築は均質」：地域ごとに、気候、素材、王朝、宗派の違いがあります。モロッコ、エジプト、トルコ、イラン、インドは、それぞれ別の伝統です。

3-2 中国 ― 陶磁器・木・庭園の文明

何を作ったのか

中国は、陶磁器、絹、漆器、青銅器、玉器、木工、建築、庭園、印刷、紙、書道、印章など、驚くほど多様なデザイン伝統を持っています。ここでは、特に世界に影響を与えた陶磁器、明式家具、庭園、印刷を扱います。

陶磁器 ― 土と火の科学

中国の陶磁器は、新石器時代の彩陶（仰韶文化、紀元前5000〜3000年ごろ）から始まり、商周時代の青銅器、漢代の釉陶、唐代の三彩、宋代の青磁・白磁、元代の青花、明代の五彩、清代の粉彩へと発展します。

  • 宋代の五大名窯：汝（じょ）、官、哥、定、鈞（きん）。汝窯の青磁は、雨上がりの空のような色と評されます。定窯の白磁は、繊細な印花・刻花で知られます。
  • 景徳鎮：元・明・清の官窯。青花は、ペルシア産のコバルト（スマルト）を使い、白地に青で絵を描きます。14世紀に急速に発展し、ヨーロッパに輸出されて「china」という言葉が陶磁器の代名詞になりました。
  • 釉薬の科学：灰釉、長石釉、鉄釉、銅紅釉。還元焼成と酸化焼成の違いが、色を決めます。陶工は、温度と酸素を微妙に調整する、高度な技術を持っていました。

赤ちゃんでもわかる一言
中国の陶磁器は、「土を焼くと、ガラスのように輝く」という発見から始まりました。色は、絵の具ではなく、火の加減で生まれます。

明式家具 ― 木のミニマリズム

明時代（1368〜1644年）の家具は、明式家具として知られています。特徴は、以下の通りです。

  • 素材：黄花梨（こうかり、huanghuali）、紫檀（したん、zitan）などの硬木。輸入材も使われました。
  • 構造：釘を使わず、ほぞと仕口で組む。湿度や収縮に強い。
  • 形態：直線と曲線のバランス。余分な装飾を削ぎ、木目を活かす。
  • 人間工学：椅子の背もたれのカーブ、肘掛けの高さ、座面の広さ。
  • 象徴：文人の教養、簡素、自然との調和。

明式家具は、20世紀の北欧デザインやモダニズムにも影響を与えたと言われます。ただし「明式＝ミニマリズム」と単純化すると、中国家具の多様性（清式の華麗さ、民間の素朴さ）を見失います。

庭園 ― 借景と余白

中国の庭園、特に蘇州の文人庭園は、「借景（しゃっけい）」、「対景」、「漏景」などの手法で知られます。壁の向こうの塔を借りて景色にする。窓の形で景色を切り取る。曲がりくねった廊下で、歩くたびに景色を変える。池、石、竹、梅、蘭、菊。小さな空間に、宇宙を作ります。

庭園は、単なる装飾ではありません。隠遁、読書、詩作、交友のための空間であり、文人の理想を体現するデザインです。中国の庭園は、日本の庭園にも大きな影響を与えました。

建築 ― 木のフレームと「間」

中国建築の基本は、木造の柱と梁、斗栱（ときょう）、屋根の反り、中庭です。建物は、「間（けん）」という単位でモジュール化され、必要に応じて増築できます。これは、現代の「モジュラー建築」の先駆けです。

  • 紫禁城（北京、15世紀）：軸線の儀礼空間。南から北へ、門、広場、大殿。
  • 天壇（16世紀）：円と四角の宇宙観。青い瓦、三層の円丘。
  • 福建土楼：円形・方形の集合住宅。防御と共同体の設計。
  • 風水：地形、方位、水の流れを読む環境設計の知識。迷信と科学が混ざっていますが、日照・排水・防風の実用的な知恵も含みます。
印刷と書物

中国は、紙（105年ごろ）、木版印刷（7〜8世紀）、活字（1040年ごろ、畢昇）の発明国です。木版印刷は、文字と絵を同時に印刷でき、大衆文化（年画、小説、教科書）を支えました。活字は、漢字の数が多く、木版に比べて効率が悪かったため、中国では木版が主流でした。それでも、活字のアイデアは、朝鮮、日本、ヨーロッパへと広がりました。

誤解を解く
  • 「中国デザインは装飾過多」：明式家具や宋代青磁のように、極端な簡素さを追求する伝統もあります。
  • 「中国は近代まで科学がなかった」：製陶、製紙、印刷、建築、造船、時計、火薬、羅針盤など、高度な技術と設計がありました。
  • 「中国は均質」：南北、漢族と少数民族、宮廷と民間で、デザインは大きく異なります。

3-3 インド ― 都市・神殿・布の文明

ハラッパー都市計画

インダス文明（紀元前2600〜1900年ごろ）のモヘンジョ・ダロやハラッパーは、格子状の街路、下水道、公共浴場、標準化されたレンガ、統一された重量を持っていました。これは、古代世界でも突出した都市計画です。

  • 街路は、ほぼ東西・南北に走る。
  • 家屋は、中庭を囲み、浴室と排水設備を持つ。
  • レンガの寸法は、ほぼ統一されている（1:2:4の比率）。
  • 穀物を測る分銅も、標準化されている。

これは、単なる「近代的な都市」の先駆けではありません。衛生、物流、行政、宗教が一体となった、独自の都市デザインです。

ヴァーストゥ・シャーストラ

ヴァーストゥ・シャーストラは、古代インドの建築・空間設計の理論書です。直訳すると「建築の科学」。敷地の選び方、方位、寸法、部屋の配置、建築儀礼などを扱います。

  • 方位（北、東、南、西）と神々の配置。
  • 中心（ブラフマ・スターナ）の重要性。
  • 素材、比例、装飾の規則。
  • 建築前の儀礼と浄化。

ヴァーストゥは、宗教的な宇宙観と、実用的な環境設計（日照、風、水）が混ざった体系です。現代のインドでも、住宅設計に取り入れる人がいます。ただし、すべてのインド建築がヴァーストゥに従ったわけではなく、地域ごとの独自の伝統もあります。

ストゥーパ、神殿、ジャーリー
  • ストゥーパ：仏舎利を納める半球形の塔。サーンチーのストゥーパ（紀元前3世紀ごろ）は、門（トラナ）の彫刻で知られます。
  • 石窟寺院：アジャンタ、エローラ。岩を掘って、寺院と僧院を作る。
  • ヒンドゥー神殿：グプタ時代（4〜6世紀）に基礎ができ、中世に発展。カーンチープラム、マドゥライ、コナーラク（13世紀）の太陽神殿。
  • ジャーリー：透かし彫りの石スクリーン。光と風を通し、女性の空間を守る。ムガル建築の代表。
  • チャハール・バーグ：ペルシア起源の四分割庭園。タージ・マハル（1632〜53年）の庭園は、その典型。
布 ― インドの最大のデザイン輸出

インドは、綿、絹、染料、織り、刺繍の文明です。

  • ムスリン：ベンガル地方の極細の綿布。「織物の空気」と呼ばれるほど薄い。
  • チンツ：綿布に、手描きまたは木版で花模様を描いたもの。17〜18世紀にヨーロッパで大流行し、イギリスの綿工業に影響を与えました。
  • イカット：糸を染めてから織る技法。模様がかすれる独特の風合い。
  • バンドハニ：結び染め。
  • カンタ：ベンガルの刺繍。古布を重ね、刺し子で模様を作る。修理と再利用のデザイン。
  • コロック：床に描く幾何学模様。毎朝、女性が描く、儚い（ephemeral）デザイン。

一歩深く（専門家向け）
インドの綿織物は、産業革命の前提を作りました。イギリスはインドから綿布を輸入し、その模様を模倣し、機械織機で大量生産しました。やがてインドの手織り産業は衰退し、ガンディーはチャルカ（手紡ぎ車）を政治的な象徴にしました。デザインは、帝国の収奪と抵抗の現場でもあったのです。

誤解を解く
  • 「インドは精神性だけの文明」：都市計画、数学、天文学、冶金、織物、建築の高度な技術があります。
  • 「ヴァーストゥは万能の設計法」：地域・宗派・時代によって多様で、すべての建築に当てはまるわけではありません。
  • 「インドの布は伝統的で変わらない」：交易、植民地化、産業化の中で、絶えず変化してきました。

3-4 アフリカ ― 布と建築のデザイン

アディンクラ ― ことわざを着る

アディンクラは、ガーナのアカン族の象徴的な模様です。布にスタンプで押し、意味のある記号を並べます。記号は、ことわざ、教訓、歴史、信仰を表します。

  • サンコファ（戻って取りに行く）：鳥が後ろを向いている姿。過去から学ぶ。
  • ギャ・ニャメ（神の至高性）：神のみが万物を超えている、という意味。
  • ドゥエニメン（雄羊の角）：力と謙虚さ。
  • ンサー（編み目の模様）：品質と熟練。

アディンクラは、単なる模様ではありません。文字に頼らずに、ことわざを布に埋め込む、情報デザインです。葬儀、成人式、王の儀礼などで使われます。

ケンテ ― 王の織物

ケンテは、ガーナのアサンテ族とエウェ族の織物です。細い帯を織り、それを縫い合わせて大きな布にします。色と模様には意味があります。

  • 金：富、王権。
  • 赤：血、犠牲、政治的緊張。
  • 緑：成長、再生。
  • 青：平和、愛。
  • 黒：成熟、精神性。

ケンテは、王の儀礼、結婚式、成人式、葬儀で使われます。1990年代以降、アメリカの大学の卒業式でケンテのストールを着ける習慣が広がり、アフリカ系アメリカ人のアイデンティティ表現になりました。同時に、大量生産の模倣品や文化の商業化という問題もあります。

ボゴランフィニ ― 泥で描く

ボゴランフィニは、マリのバマナ族の泥染め布です。綿布を発酵させた泥で染め、鉄分を含む泥で模様を描きます。女性が知識と技法を継承します。幾何学模様は、社会的身分、通過儀礼、性別を示します。

ンダベレの家 ― 女性が描く建築

南アフリカのンダベレ族の家は、女性が幾何学模様で描きます。白、黒、赤、黄、緑の強いコントラスト。壁面は、単なる装飾ではなく、家族の歴史、女性の技術、共同体の誇りを表します。19世紀末から20世紀にかけて、植民地化と観光の影響で、模様はより大胆に、商業的になりました。

大ジンバブエ ― モルタルなしの石造建築

大ジンバブエ（11〜15世紀）は、ジンバブエの石造遺跡です。モルタルを使わず、石を積み上げて壁を作ります。高さ11メートル、長さ250メートルの大囲壁。貿易、宗教、王権の中心でした。ヨーロッパの考古学者は、これを「アフリカ人の建築ではない」と主張しましたが、現在ではアフリカの建築であることが確立しています。デザインの歴史は、人種主義と戦ってきた歴史でもあります。

その他の例
  • ドゴン族の建築（マリ）：崖に張り付く村落。穀物庫、祭壇、集会場。宇宙観と建築の対応。
  • ラリベラの岩窟教会（エチオピア、12〜13世紀）：岩を掘り下げて作った教会群。
  • クバのラフィア織物（コンゴ）：切りパイル法による幾何学模様。
  • ガーナの幻想棺：故人の職業や趣味を象徴する棺。デザインが死とユーモアを扱う例。
  • ヨルバのビーズ細工：王権と宗教の象徴。
誤解を解く
  • 「アフリカは一つの文化」：54カ国、数千の言語と民族。デザインは驚くほど多様です。
  • 「アフリカのデザインはプリミティブ」：幾何学、色彩、構造、意味の高度な体系があります。
  • 「アフリカの工芸は作者不明」：共同体の作者性（authorship）は、個人の作者性とは別の制度です。匿名性は、未熟さではなく、別の価値観です。

3-5 先住アメリカ ― 結縄・都市・暦

マヤ ― 都市と文字と暦

マヤ文明（紀元前2000年ごろ〜16世紀）は、現在のメキシコ南部、グアテマラ、ベリーズ、ホンジュラスに栄えました。ティカル、パレンケ、コパンなどの都市には、ピラミッド、宮殿、球戯場、広場、貯水池がありました。

  • 文字：マヤ文字は、音節と表語を組み合わせた体系。石碑、陶器、絵文書（コデックス）に記されました。
  • 暦：260日のツォルキン暦と365日のハアブ暦、長期暦。天文学と建築の配置。
  • 陶器：彩色土器。神話、王、儀礼、文字。
  • 都市計画：方位、天文、水管理、宗教的中心。

マヤの都市は、ヨーロッパの「格子都市」とは違います。地形、水、暦、宗教に合わせた、有機的な配置です。しかし、計画的でないわけではありません。別の計画原理です。

アステカ ― 湖の上の都市

テノチティトラン（1325年建設）は、テスココ湖の島に作られた都市です。チナンパ（人工の浮き島）で農地を広げ、運河、堤防、水道橋、市場、神殿を作りました。スペイン人征服者たちは、その規模と清潔さに驚きました。

  • テンプロ・マヨール：大神殿。二つの祠堂、蛇の彫刻、生贄の儀礼。
  • コデックス：絵文書。歴史、暦、貢納、儀礼。
  • 羽毛細工：ケツァールの羽などを使った、色と光のデザイン。
  • 市場：何万人も集まる交易の場。品質管理と規格。
インカ ― 結縄と道路と段々畑

インカ帝国（15〜16世紀）は、アンデス山脈に沿って、数万キロにおよぶ道路網（カパック・ニャン）を築きました。石を精密に組み合わせた建築（クスコ、マチュ・ピチュ）、段々畑（アンデネス）、水路、倉庫、結縄（キープ）が特徴です。

  • キープ：紐の結び目で、数字や情報を記録する。色、位置、結び方、撚り方に意味がある。単なる記憶補助ではなく、行政の記録システムだと考えられています。完全には解読されていません。
  • 石組み：モルタルなしで、地震に強い。石の形を精密に加工し、組み合わせる。
  • 段々畑：急斜面を農地に変える。土壌流出を防ぎ、水を管理する。
  • ミタ：共同体の労働義務。公共事業を支える制度。

赤ちゃんでもわかる一言
インカのキープは、「紐の結び目で作ったExcel」のようなものです。文字を使わずに、数量や行政の情報を記録しました。

北アメリカ
  • プエブロ建築：日干しレンガ、石、木材。チャコ・キャニオン（850〜1150年）の大規模集落。太陽と暦に合わせた配置。
  • ナバホの織物：羊の毛を使った織物。幾何学模様。19世紀以降、観光市場向けに変化。
  • トーテムポール：北西海岸の先住民。家系、物語、権利を刻む。
  • ナスカの地上絵：紀元前500〜紀元後500年ごろ。動物、植物、幾何学図形。水と儀礼に関係するという説。
誤解を解く
  • 「先住アメリカには都市がなかった」：マヤ、アステカ、インカ、プエブロなど、大規模な都市文明がありました。
  • 「文字がなければ歴史がない」：キープ、絵文書、口承、建築、織物が、歴史を記録していました。
  • 「先住文化は静的」：交易、戦争、気候変動、植民地化の中で、絶えず変化しました。

3-6 オセアニア ― 航海と大地のデザイン

ポリネシアの航海術

ポリネシア人は、星、太陽、月、波、風、雲、鳥の飛び方、海の色を読み、太平洋の島々を航海しました。星のコンパス、波の航海術などの知識体系を持ち、ミクロネシア（マーシャル諸島）にはスティック・チャート（棒と貝で作った海図）の伝統がありました。

  • 星の位置と動きを記憶し、航路を決める。
  • 波の反射と干渉を読み、島の方向を推測する。
  • 鳥の飛行パターンから、陸地の近さを知る。
  • 雲の形から、山の位置を推測する。

これは、地図を持たずに、身体と記憶と自然の信号でナビゲートする、高度な情報デザインです。現代のウェイファインディング（道案内）の研究にも通じます。

マオリとアボリジナル
  • マオリ：ワカイロ（木彫）、マラエ（集会場）、コーワイワイ（kōwhaiwhai、幾何学模様）、トゥクツク（tukutuku、織物パネル）。家系、神話、土地の権利を刻む。
  • アボリジナル・オーストラリア：ドット・ペインティング（1970年代以降の現代アート運動として世界的に知られる）、樹皮画、ブーメラン、魚罠、火を使って大地を管理するファイアスティック・ファーミング。デザインは、土地との関係を維持する技術です。
  • トレス海峡諸島：精緻な彫刻、仮面、織物。海と交易の文化。
誤解を解く
  • 「オセアニアは小さな島の文化」：太平洋は、地球の表面の3分の1。航海術は、宇宙規模の知識です。
  • 「先住のデザインは消えた」：植民地化で大きな打撃を受けましたが、現在も継承され、現代アートやデザインに影響を与えています。

3-7 この章が変えるもの

西洋の外のデザインを見ると、次のことがわかります。

  1. デザインの定義は、一つではない。 幾何学模様は数学であり、祈りであり、装飾です。布は、衣服であり、記憶であり、身分です。都市は、行政であり、宇宙観です。
  2. 「装飾」は、余分なものではない。 装飾は、意味、身分、信仰、歴史を運ぶ、高度な情報技術です。
  3. 「工芸」は、未熟なデザインではない。 工芸は、素材、技術、共同体の知識を統合した、別の合理性です。
  4. 「作者」の概念は、一つではない。 個人の天才、共同体の匿名性、職人の署名。それぞれの制度があります。
  5. 近代の「普遍」は、しばしば地方の特殊だった。 ヨーロッパのモダニズムは、世界の多様なデザインを「遅れたもの」と見なしましたが、それは一つの地方の視点でした。

歴史の教訓
デザインの歴史は、ヨーロッパの歴史ではない。
世界には、別の合理性、別の美、別の作者性がある。
それらを「未熟」と呼ぶのは、無知か、傲慢か、その両方である。
本当のデザイン史は、複数の近代を、複数の完成形として並べる。

中世 ― 職人の世界

中世ヨーロッパ（5〜15世紀）のデザインは、ギルド（同業者組合）が支えていました。石工、大工、織工、金工、革工、染工、陶工。それぞれが、徒弟、職人、親方の階梯を持ち、品質、価格、訓練、参入を管理しました。

ギルドのデザインは、注文生産が中心です。顧客の注文を受け、職人が材料を見て、作りながら形を決めます。設計図はあっても、細部は職人の判断に委ねられます。知識は、身体と徒弟制を通じて伝えられました。

  • 大聖堂：ロマネスク（10〜12世紀）、ゴシック（12〜16世紀）。尖頭アーチ、リブ・ヴォールト、フライング・バットレス、ステンドグラス。構造と光の設計。
  • 写本：修道院の写字室。羊皮紙、インク、金箔、彩飾。文字と絵のレイアウト。
  • タペストリー：貴族の権力と物語。羊毛、絹、金糸。
  • 金属器：聖杯、聖遺物容器、武器、鎧。鋳造、鍛造、象嵌。
  • 家具：木、鉄、皮革。移動式、折りたたみ式。城の生活。

中世のデザインは、決して「暗黒時代」ではありません。ゴシック建築の構造計算、ステンドグラスの色彩設計、写本のタイポグラフィは、高度な知識と技術の産物です。

赤ちゃんでもわかる一言
中世のデザインは、職人が「作りながら考える」世界でした。設計図より、手と材料の対話が中心でした。

ルネサンス ― 「デザイン」が頭のなかに入る

ルネサンス（14〜16世紀）は、デザインの歴史における大きな転換点です。「disegno（構想・図画）」が、制作から独立した価値を持ち始めます。

  • 遠近法：ブルネレスキが約1413年に実験し、アルベルティが1435年に理論化。平面に奥行きを描く技術。
  • ウィトルウィウス：古代ローマの建築家。『建築十書』が1414年に再発見され、比例、秩序、耐久性、有用性、美の理論が復活。
  • アルベルティ：『建築論』（1452年ごろ）。建築を、数学と社会の設計として論じる。
  • レオナルド・ダ・ヴィンチ：解剖、機械、都市計画、絵画。芸術と工学の融合。
  • ヴァザーリ：『芸術家列伝』（1550年）。芸術家を「天才」として扱う、近代の作者概念の原型。

ルネサンスのデザインは、「構想」と「制作」の分離を進めました。建築家は、図面を描き、現場を監督します。画家は、遠近法と解剖学を使って、現実を再構成します。デザインは、職人の技から、知識人の構想へと重心を移します。

一歩深く（専門家向け）
ルネサンスの「disegno」は、単なる「デッサン」ではありません。心のなかのイメージ（concetto）と、それを線で表す行為（disegno）の両方を含みます。この概念が、後に「デザイン」の近代的な意味（構想、計画、意匠）の基礎になります。一方で、職人の知識は「機械的術」として、自由七科（文法、修辞、論理、算術、幾何、天文、音楽）より低く見られるようになります。デザインの地位が上がる一方で、作る人の地位が下がる、という逆説が生まれます。

印刷 ― デザインが複製される

15世紀半ば、ヨハネス・グーテンベルクが、活版印刷を実用化します。金属活字、油性インク、ブドウ絞り機を組み合わせ、1455年ごろに『42行聖書』を印刷しました。

印刷は、デザイン史に革命をもたらします。

  • 複製：同じ本を、何百部も作れる。
  • 標準化：活字のサイズ、行間、余白、ページ構成が、規格になる。
  • 普及：知識が、修道院や宮廷から、都市の市民へ広がる。
  • 公共圏：印刷物が、宗教改革、科学革命、政治革命を支える。
  • 作者性：印刷された本は、著者、印刷者、出版者、販売者の分業を生む。

アルドゥス・マヌティウス（アルド）は、1494年にヴェネツィアでアルディーネ印刷所を設立します。ギリシア語・ラテン語の古典を印刷し、1501年にはイタリック体を導入しました。小型の八折版（オクターヴォ）は、持ち運べる本を作り、読書のスタイルを変えました。句読点、ページ番号、索引、目次。現代の本のデザインの基礎は、この時代に作られました。

赤ちゃんでもわかる一言
印刷は、「同じ本をたくさん作る」発明です。でも本当に変えたのは、知識を一部の特権から、多くの人へ広げたことです。

パターンブック ― 様式のコピー＆ペースト

印刷は、デザインの様式も複製しました。16世紀には、パターンブック（図案集）が流行します。建築の柱頭、家具の彫刻、装飾の唐草、文字の書体。職人は、図案集から模様を選び、注文に合わせて組み合わせました。

  • セルリオ『建築書』（1537年〜）：建築の図面と遠近法。
  • パラディオ『建築四書』（1570年）：ヴィラの設計。後に英米のパッラディアン建築に影響。
  • ディッテルリン『建築の装飾』（1598年）：マニエリスムの装飾。
  • クレスの刺繍本、ヴィンチョーロの文字本。

パターンブックは、デザインの「コピー＆ペースト」を可能にしました。地方の職人も、都市の流行を模倣できます。一方で、様式の均質化、地域の伝統の喪失も進みます。印刷は、デザインの民主化と標準化を、同時に進めたのです。

大航海時代 ― デザインの混血

15世紀末から、ヨーロッパは海を越えて、アジア、アフリカ、アメリカと結びつきます。デザインは、交易と征服のなかで、激しく混ざり合います。

  • 陶磁器：中国の青花が、ヨーロッパの宮廷で珍重される。デルフト陶器（オランダ）が、中国磁器を模倣する。
  • 織物：インドの更紗（サラサ）が、ヨーロッパで大流行。フランスのトワル・ド・ジュイが、インド更紗を模倣する。
  • 漆器：日本の蒔絵が、ヨーロッパの家具に影響。シノワズリ（中国趣味）が、18世紀の装飾を席巻。
  • 珈琲・茶・砂糖：飲み物のデザイン（カップ、ポット、テーブル）が変わる。植民地のプランテーションが、砂糖と陶磁器の大量消費を支える。
  • 銀：南米の銀が、ヨーロッパとアジアの交易を動かす。銀の流通が、陶磁器、絹、茶のデザインを変える。

デザインの混血は、創造性を生む一方で、収奪と搾取の上に成り立っていました。中国磁器の美しさは、景徳鎮の職人の労働と、アジア間の交易の上にあります。インド更紗の華やかさは、インドの織工の技術と、イギリスの商業資本の上にあります。デザインの歴史を語るとき、この影を忘れてはいけません。

バロックとロココ ― 権力の演出

17〜18世紀のヨーロッパは、絶対王政の時代です。デザインは、権力を演出する装置になります。

  • ヴェルサイユ宮殿（1682年、ルイ14世）：鏡の回廊、幾何学庭園、噴水、軸線。太陽王の権力を、空間で表現。
  • バロック：曲線、劇的な光、過剰な装飾。ベルニーニの彫刻、ボロミーニの建築。
  • ロココ：非対称、繊細な曲線、パステルカラー、中国趣味。ポンパドゥール夫人のサロン、マイセン磁器、シュヴルーズ。
  • チッペンデール『家具指針』（1754年）：家具の図案集。ロココ様式をイギリスに広める。

バロックとロココは、しばしば「過剰」と批判されます。しかし、それらは、光、鏡、水、磁器、織物を総動員した、マルチメディアの空間デザインでした。権力は、美しさを通じて、身体に刻まれます。

啓蒙主義 ― 分類と標準化

18世紀は、分類と標準化の時代です。

  • 百科全書（1751〜1772年、ディドロとダランベール）：知識を分類し、図版で示す。デザインの知識も、図版で伝達される。
  • 植物分類（リンネ）：自然を分類する視点が、デザインのモチーフにも影響。
  • 工学学校：1747年、フランスに橋梁学校（École des Ponts et Chaussées）。1794年、エコール・ポリテクニーク。技術者教育の制度化。
  • 特許制度：発明を保護し、産業を促す。デザインの「作者」と「所有」が、法的に定義される。
  • 博物館：大英博物館（1753年）、ルーヴル（1793年）。文化を分類し、展示する。

啓蒙主義は、デザインに「合理性」と「普遍性」の理念をもたらしました。しかし、その普遍は、しばしばヨーロッパの特殊性でした。分類は、序列を作り、序列は、支配を正当化しました。

第5章 産業革命とデザインの誕生 ― 1851年、機械が美しさを問うた日

7,223 CHARACTERS約 14 分

なぜイギリスだったのか

18世紀後半、イギリスで産業革命が始まります。石炭、鉄、蒸気機関、植民地、資本、特許、運河、そして安い労働力。これらの条件が揃った国で、物の作り方が根本から変わります。

  • 石炭：燃料。森林不足を補い、鉄と蒸気を可能にする。
  • 鉄：構造材、機械、線路。鋳鉄、錬鉄、鋼。
  • 蒸気機関：工場、鉱山、鉄道、船。エネルギーを場所から解放する。
  • 植民地：原料（綿、染料、砂糖、茶）と市場。
  • 特許：発明の所有と投資を保証する。
  • 分業：アダム・スミスが『国富論』（1776年）で、ピン工場の分業を例に、生産性の向上を論じる。

産業革命は、デザインの歴史において、「作る人」と「設計する人」を分離しました。工場の所有者は、設計図を描く人を雇い、労働者は図面に従って部品を組み立てます。ここに、近代的な「デザイナー」の原型が生まれます。

赤ちゃんでもわかる一言
産業革命は、「一人の職人が最初から最後まで作る」世界から、「多くの人が分かれて作る」世界へ変えました。だから「設計図を描く人」が必要になったのです。

ウェッジウッド ― デザインをビジネスにした最初の男

ジョサイア・ウェッジウッド（1730〜1795）は、1759年5月1日に、イギリスのスタッフォードシャーで陶器会社を創業します。彼は、単なる陶工ではありませんでした。デザインを、市場、生産、ブランド、流通のシステムに組み込んだ、最初の実業家です。

  • クイーンズ・ウェア：1765年、シャーロット王妃に認められ、宮廷御用達になる。名前がブランドになる。
  • エトルリア（1769年）：新工場。蒸気機関を使い、分業を導入。
  • カタログとショールーム：ロンドンにショールームを開き、カタログで注文を受ける。地方の顧客も、都市の流行を買える。
  • 品質管理：粘土、釉薬、焼成、絵付けを分業化し、品質を標準化。
  • マーケティング：王室、貴族、知識人を巻き込み、流行を作る。
  • 社会運動：1787年、反奴隷制のメダル「Am I not a man and a brother?」を制作。デザインが政治メッセージを運ぶ。

ウェッジウッドは、「デザインは、生産と市場のシステムのなかで機能する」ことを示しました。美しい器を作るだけでは、ビジネスにならない。誰に、どのように届け、どう使ってもらうかまで設計する。これが、近代デザインの始まりです。

ボルトンとワット ― エネルギーを売る

マシュー・ボルトンとジェームズ・ワットは、1775年に共同事業を立ち上げ、蒸気機関の製造・販売を始めます。バーミンガムのソーホー工場は、当時最大級の工業施設でした。

ボルトンは、1776年に訪問したジェームズ・ボズウェルに、こう言ったと伝えられます。

「私はここで、全世界が欲しがるものを売っている。――力（パワー）だ。」

蒸気機関は、単なる機械ではありません。時間と場所から、エネルギーを解放する装置です。工場は、川の近くから、石炭の近くへ。都市は、鉄道の周りに広がる。デザインの制約条件が、根本から変わります。

1851年 ― 世界が初めて「デザイン」を見た日

1851年5月1日、ロンドンのハイド・パークで、万国産業博覧会（Great Exhibition）が開幕します。会場は、クリスタル・パレス。鉄とガラスで作られた、巨大な温室のような建築です。

  • 設計：ジョセフ・パクストン。もともとは温室の設計者。
  • 規模：長さ約563メートル、幅約124メートル、高さ約33メートル。
  • 材料：鉄、ガラス。プレハブ式で、短期間で建設。
  • 展示：約10万点。機械、原料、陶磁器、織物、家具、武器、芸術品。
  • 来場者：約600万人。当時のロンドンの人口を超える。

クリスタル・パレスは、「工業生産の美」を初めて世界に見せました。しかし、同時に「工業製品の醜さ」も露呈しました。機械で作られた過剰な装飾、様式の寄せ集め、品質のばらつき。批評家たちは、これを「デザインの危機」と呼びます。

一歩深く（専門家向け）
クリスタル・パレスは、鉄とガラスの建築として画期的ですが、突然の天才的発明ではありません。18世紀の温室、市場、駅舎、橋などの鉄骨ガラス構造の蓄積の上にあります。また、プレハブ式の建設は、帝国のサプライチェーン（鉄、ガラス、木材、労働力）に依存していました。博覧会は、産業の勝利であると同時に、帝国の展示でもあったのです。

デザイン改革 ― 「悪趣味」を直す

博覧会の後、イギリスでは「デザイン改革」が起こります。

  • ヘンリー・コール：官僚、デザイナー、教育者。『デザイン・アンド・マニュファクチャーズ・ジャーナル』を創刊。南ケンジントン博物館（後のV&A）の設立に関わる。
  • オーウェン・ジョーンズ：建築家、デザイナー。『装飾の文法』（1856年）を出版。世界の装飾を分類し、37の原則を提示。
  • サマリー・アート・マニュファクチャーズ（1847年）：コールが、芸術家と製造業者を結びつけるために設立。
  • サウス・ケンジントン・ミュージアム（1852年/1857年）：デザイン教育のための博物館。後のV&A。

デザイン改革の目標は、「機械製品の品質を、芸術の水準まで上げる」ことでした。しかし、そこには、職人の手仕事を理想化するロマン主義と、工業化を進めたい実業家の思惑が混ざっていました。

ラスキンとモリス ― 機械に抗う美

ジョン・ラスキン（1819〜1900）は、イギリスの美術評論家です。『建築の七灯』（1849年）、『ヴェネツィアの石』（1851〜53年）で、ゴシック建築の職人的美を称賛し、産業社会の分業と機械化を批判しました。

ウィリアム・モリス（1834〜1896）は、ラスキンの思想を受け継ぎ、アーツ・アンド・クラフツ運動の中心人物になります。

  • モリス・マーシャル・フォークナー商会（1861年）：家具、壁紙、織物、ステンドグラス、タイル。
  • モリス・アンド・カンパニー（1875年）：組織を再編。
  • ケルムスコット・プレス（1891年）：手作りの美しい本。活字、紙、インク、装丁にこだわる。
  • 社会主義：1883年に社会民主連盟、1884年に社会主義同盟に参加。『ユートピアだより』（1890年）。

モリスの有名な言葉に、次のものがあります。

「あなたの家に、役に立つと知っているか、美しいと信じているもの以外、何も置いてはいけない。」

モリスは、「芸術と労働の統一」を求めました。機械による分業が、労働者を「手」にし、製品を「安っぽい大量品」にすると批判しました。しかし、モリスの製品は、手仕事のため非常に高価で、富裕層しか買えませんでした。「みんなのための芸術」を目指しながら、富裕層のための奢侈品を作るという矛盾。これが、アーツ・アンド・クラフツ運動の根本的な緊張です。

赤ちゃんでもわかる一言
モリスは「機械は人を不幸にする」と怒りました。でも、彼の手作り品は高すぎて、普通の人は買えませんでした。正しいことを言うことと、それを実現することは、別の難しさなのです。

クリストファー・ドレッサー ― 最初の工業デザイナー

クリストファー・ドレッサー（1834〜1904）は、しばしば「最初の独立した工業デザイナー」と呼ばれます。彼は、陶器、金属器、ガラス、家具、壁紙、織物など、幅広い製品をデザインし、複数のメーカーに図案を提供しました。

  • 日本美術の影響：1876〜77年の訪日で、日本の工芸に衝撃を受ける。『日本：その建築・美術・美術工芸』（1882年）。
  • 機能主義：『装飾デザインの芸術』（1862年）。「芸術は用を支配する（Art Presides over Utility）」。
  • 幾何学的形態：植物モチーフを抽象化し、機械生産に適した形にする。
  • 多様な素材：金属、陶器、ガラス、木。素材の特性を活かす。

ドレッサーは、モリスとは逆の道を選びました。機械生産を否定せず、機械で美しいものを作る。この姿勢が、後のバウハウスや近代デザインに通じます。

アール・ヌーヴォー ― 曲線の革命

19世紀末、ヨーロッパでアール・ヌーヴォーが起こります。特徴は、有機的な曲線、植物モチーフ、総合芸術（建築、家具、装飾、グラフィックの統一）です。

  • ヴィクトール・オルタ：ベルギーの建築家。タッセル邸（1893年）。鉄とガラスの構造を、曲線の装飾として見せる。
  • ヘクトール・ギマール：パリのメトロ入口（1900年）。鋳鉄の曲線。
  • アルフォンス・ミュシャ：ポスター。女性と植物の曲線。
  • ルイ・コンフォート・ティファニー：ステンドグラスとランプ。
  • エミール・ガレ：ガラス器。植物と昆虫のモチーフ。
  • アントニ・ガウディ：バルセロナのサグラダ・ファミリア、グエル公園。構造と装飾の融合。

アール・ヌーヴォーは、「近代の技術」と「自然の曲線」を結びつけようとしました。鉄、ガラス、印刷、大量生産の技術を使いながら、有機的な美を追求します。しかし、その装飾性は、やがて「過剰」と批判され、モダニズムの直線的な美学に取って代わられます。

ウィーン分離派とウィーン工房

1897年、ウィーンで分離派が結成されます。クリムト、ホフマン、モーザー、オルブリヒ。伝統的なアカデミーから分離し、新しい芸術を模索します。

  • ウィーン分離派会館（1898年）：ヨーゼフ・マリア・オルブリヒ設計。黄金の月桂樹のドーム。
  • ウィーン工房（1903〜1932年）：ホフマンとモーザーが設立。家具、食器、織物、宝石、グラフィック。総合芸術の工房。
  • アドルフ・ロース：分離派を批判し、装飾を否定する。「装飾と犯罪」（1908年講演、1910年再講演、1913年出版）。

ロースの主張は過激です。

「文化の進化は、日用品から装飾を除去することと同義である。」

しかし、ロースは無装飾の機能主義者ではありませんでした。彼は、大理石、木、真鍮などの素材の質を重視し、内部空間には豊かな素材を使いました。「装飾を否定した」のではなく、「安っぽい模様を否定した」のです。この微妙な違いは、しばしば誤解されます。

一歩深く（専門家向け）
『装飾と犯罪』は、単なる美学の論文ではありません。ロースは、装飾を「未開の文化」や「犯罪者・退化した者」の特徴と結びつける、人種主義的・進化論的なレトリックを使っています。この点は、今日の視点から強く批判されるべきです。一方で、装飾を「労働と材料の浪費」と見る経済的批判は、環境デザインの先駆けとも言えます。テキストを読むときは、美的主張と人種的偏見を分けて評価する必要があります。

ドイツ工作連盟 ― 標準化か、個性か

1907年、ドイツでドイツ工作連盟（Deutscher Werkbund）が結成されます。目的は、芸術家、建築家、デザイナー、産業界を結びつけ、ドイツ製品の国際競争力を高めることでした。

  • 創設者：ヘルマン・ムテジウス、ペーター・ベーレンス、リヒャルト・リーマーシュミット、ブルーノ・パウル、ヨーゼフ・ホフマンら。
  • 背景：イギリスのアーツ・アンド・クラフツ運動と、アメリカの大量生産の脅威。
  • 主張：「質の高い大量生産」。手工芸の質を、機械生産に移植する。

1914年、ケルンで開かれた工作連盟の大会で、ムテジウスとアンリ・ヴァン・デ・ヴェルデが激しく対立します。

  • ムテジウス：標準化（Typisierung）を進め、規格に基づく大量生産を主張。ドイツの国際競争力を高める。
  • ヴァン・デ・ヴェルデ：芸術家の個性と創造性を守る。標準化は、芸術を殺す。

この対立は、「デザインにおける個人とシステムの緊張」の原型です。今日のデザインシステム、ブランドガイドライン、プラットフォームの標準化にも、同じ緊張があります。

ベーレンスとAEG ― 最初のコーポレート・アイデンティティ

ペーター・ベーレンス（1868〜1940）は、1907年にドイツの電機会社AEGの芸術顧問に就任します。彼は、製品、ポスター、カタログ、店舗、建築、ロゴを統一的にデザインしました。これは、世界最初の本格的なコーポレート・アイデンティティ（CI）の一つとされます。

  • AEGタービン工場（1909年）：鉄とガラスの巨大な工場。機能美と記念碑性。
  • 電球、扇風機、湯沸かし器、時計：規格化された製品群。
  • ロゴ、書体、広告：一貫した視覚言語。
  • 建築家の教育：グロピウス、マイヤー、ミースがベーレンスの事務所で働く。

ベーレンスは、「デザイナーは、企業の全体像を設計する」というモデルを作りました。製品単体ではなく、企業の顔、音、空間、体験を設計する。このモデルは、後のブラウン、ソニー、アップルに受け継がれます。

テイラーとフォード ― 人間を機械に合わせる

フレデリック・ウィンスロー・テイラー（1856〜1915）は、科学的管理法（テイラリズム）を提唱します。作業を細かく分解し、時間を測定し、最も効率的な方法を標準化します。『科学的管理法の原理』（1911年）。

ヘンリー・フォード（1863〜1947）は、1908年にモデルTを発売し、1913年にmoving assembly line（流れ作業）を導入します。1914年には、労働者の日給を5ドルに引き上げ、8時間労働を導入します。1927年までに、1500万台のモデルTが生産されました。

  • 大量生産：部品の標準化、互換性、流れ作業。
  • 大量消費：価格を下げ、労働者も消費者にする。
  • 規格：モデルTの部品は、交換可能。
  • 労働：単純化、反復、監視。労働者は、機械の一部になる。

テイラーとフォードは、「デザインの対象を、製品からシステムへ」広げました。工場、物流、労働、消費。これら全体を設計しないと、大量生産は成立しません。同時に、人間を機械に合わせるという問題を生みました。チャップリンの『モダン・タイムス』（1936年）は、その風刺です。

アメリカの工業デザイン ― 流線型と欲望

1920〜30年代、アメリカで工業デザインが職業として確立します。背景には、大恐慌、過剰生産、消費刺激があります。

  • レイモンド・ロウイ（1893〜1986）：冷蔵庫（コールドスポット、1934年）、鉄道機関車、スタデベイカー、シェル、エクソン、BPのロゴ。MAYA（Most Advanced Yet Acceptable）の原則。
  • ノーマン・ベル・ゲデス（1893〜1958）：『ホライズン』（1932年）、フューチュラマ（1939年ニューヨーク万博、GM館）。未来の高速道路と都市の模型。
  • ヘンリー・ドレイフス（1904〜1972）：『人のためのデザイン』（1955年）。人間工学、人体計測。ジョンとジョセフィンの人体チャート。
  • ウォルター・ドーウィン・ティーグ（1883〜1960）：コダック、フォード、Texaco。企業の視覚統一。

流線型（streamline）は、1930年代のアメリカを象徴する様式です。鉄道、車、冷蔵庫、トースター、鉛筆削りまで、涙形の曲線をまといます。空気抵抗の合理性がある場合もありますが、多くは「速度」「未来」「進歩」の象徴でした。

赤ちゃんでもわかる一言
1930年代のアメリカでは、冷蔵庫まで流線型になりました。速くないのに、速く見える。デザインは、機能だけでなく、夢を売るようになったのです。

計画的陳腐化 ― 壊れるように作る

大量生産と大量消費は、計画的陳腐化（planned obsolescence）という問題を生みます。製品を、一定期間で壊れるように、または古く見えるように設計する。

  • 1932年、バーナード・ロンドンが『計画的陳腐化による不況の終焉』を発表。
  • 1954年、デザイナーのブルックス・スティーブンスは、計画的陳腐化を「買い手に、必要以上に早く、少し新しく、少し良いものを欲しがらせること」と定義。
  • 自動車のモデルチェンジ、ファッションの季節サイクル、家電の修理困難。

計画的陳腐化は、経済成長を支える一方で、資源の浪費、廃棄物、修理の困難を生みます。この問題は、20世紀後半の環境運動、そして21世紀のサーキュラー・エコノミー、修理する権利へと続きます。

歴史の教訓

歴史の教訓
産業革命は、デザインを「職業」にした。
しかし、同時に「誰が設計し、誰が作るか」という分断を生んだ。
1851年の博覧会は、機械の力を誇示し、機械の醜さを露呈した。

20世紀初頭の爆発

20世紀初頭、ヨーロッパの芸術とデザインは、爆発的に実験します。

  • 未来派（1909年、マリネッティ）：速度、機械、戦争を称賛。伝統を破壊せよ。
  • キュビズム（1907年ごろ、ピカソ、ブラック）：多視点、平面の再構成。
  • シュプレマティズム（1915年、マレーヴィチ）：黒い正方形。絶対的な幾何学。
  • 構成主義（1919〜20年、タトリン、ロトチェンコ）：芸術を社会の建設に結びつける。
  • デ・ステイル（1917年、モンドリアン、ファン・ドゥースブルフ）：新造形主義。直線、矩形、原色。
  • バウハウス（1919年、グロピウス）：芸術と工芸と工業の統合。
  • ヴフテマス（1920年、モスクワ）：ロシアの「バウハウス」。

これらの運動は、互いに影響し合い、競争し、時に政治的対立を抱えながら、「新しい人間のための新しい形」を模索しました。

赤ちゃんでもわかる一言
20世紀初頭のデザイナーたちは、「古い様式を捨てて、機械の時代にふさわしい新しい形を作ろう」と燃えていました。その実験が、モダニズムです。

バウハウス ― 学校が世界を変えた

創設

1919年4月1日、ヴァルター・グロピウス（1883〜1969）が、ドイツのヴァイマールに国立バウハウスを設立します。前身は、ザクセン大公美術学校と工芸学校。グロピウスは、美術と工芸を統合し、「建築を中心とした総合芸術」を目指しました。

バウハウスの宣言（1919年）の趣旨は、次のようなものです（逐語訳ではありません）。

建築家、彫刻家、画家。われらは手仕事に戻り、職人と芸術家のあいだの傲慢な壁を取り払って、新しい職人のギルドを作ろう。

グロピウスは、「建築（Bau）」と「家（Haus）」を組み合わせて、Bauhausという言葉を作りました。職人のギルド「バウヒュッテ」へのオマージュでもあります。

三つの都市、三人の校長
  • ヴァイマール（1919〜1925）：表現主義の影響。ヨハネス・イッテンの予備課程。陶芸、織物、金属、家具、壁画、印刷の工房。
  • デッサウ（1925〜1932）：グロピウス設計の校舎（1926年）。「芸術と技術 ― 新しい統一」。工業生産との結びつき。ハンネス・マイヤー（1928〜1930）は、機能主義と社会主義を徹底。ミース・ファン・デル・ローエ（1930〜1933）は、建築と美学に集中。
  • ベルリン（1932〜1933）：廃工場を借りて存続。1933年、ナチスの圧力とゲシュタポの介入のなかで閉校。
教育 ― 予備課程と工房

バウハウスの教育は、予備課程（Vorkurs）と工房（Werkstatt）から成ります。

  • 予備課程：素材、色彩、形態、構成の基礎。ヨハネス・イッテン、ラースロー・モホイ＝ナジ、ヨーゼフ・アルバースが担当。
  • 工房：陶芸、織物、金属、家具、壁画、印刷、舞台。マイスター（親方）と芸術家がペアで教える。
  • 建築：1927年から。グロピウス、マイヤー、ミース。
  • 理論：パウル・クレー、カンディンスキー、モホイ＝ナジによる色彩・形態論。

バウハウスは、「デザインの基礎教育」というモデルを作りました。今日の美術大学・デザイン学校の基礎課程は、少なからずバウハウスの影響を受けています。

一歩深く（専門家向け）
バウハウスの予備課程は、単なる技術訓練ではありません。イッテンは、素材の触覚と色彩の心理を重視し、東洋哲学や神秘主義の影響を受けました。モホイ＝ナジは、光、運動、空間、写真、映画を統合し、「新視覚（Neues Sehen）」を提唱しました。アルバースは、紙の折り曲げと素材の経済性を通じて、形の生成を教えました。バウハウスの教育は、統一されているようで、実は教師ごとに大きく異なります。

1923年の展覧会とハウス・アム・ホルン

1923年、バウハウスは「芸術と技術 ― 新しい統一」をテーマに、大規模な展覧会を開きます。目玉は、ハウス・アム・ホルン（Haus am Horn）。バウハウスの教師と学生が設計した、実験住宅です。

  • 鉄筋コンクリート、平屋根、機能的な間取り。
  • キッチン、浴室、寝室、子供部屋、書斎。
  • 家具、照明、織物、食器まで、トータルにデザイン。
  • 「新しい生活様式」の提案。

この住宅は、「デザインは、建築、家具、日用品、生活の全体を設計する」というバウハウスの理想を体現しました。同時に、当時のドイツの住宅事情や家族像を反映しています。

デッサウ校舎 ― ガラスの工場

1926年、デッサウに新しい校舎が完成します。グロピウス設計。

  • カーテンウォール：ガラスと鉄の連続した壁。透明性。
  • 工房棟：大きなガラス窓。仕事を見せる。
  • 管理棟：橋で工房棟とつながる。
  • 学生寮：小さな個室、バルコニー。
  • 文字：屋上に「BAUHAUS」の文字。ヘルベルト・バイヤーによるサンセリフ書体。

デッサウ校舎は、「建築は、社会の透明性と合理性の象徴である」という主張です。しかし、ガラスは夏に暑く、冬に寒いという、実用上の問題もありました。理想と現実のギャップは、ここにもあります。

女性たち

バウハウスは、女性に開かれた学校でしたが、完全に平等ではありませんでした。

  • グンタ・シュテルツル：織物工房のマイスター。バウハウス初の女性マイスター。
  • アニ・アルバース：織物。後にアメリカで教育者。
  • マリアンネ・ブラント：金属工房。照明、ティーポット、灰皿。
  • ルチア・モホイ：写真。バウハウスの記録を残す。
  • オッティ・ベルガー、イルゼ・ゴット、ベニータ・コッホ。

女性は、しばしば織物工房に誘導されました。金属や建築のような「男性的」とされた分野には、少数しか入れませんでした。バウハウスの平等は、当時の社会の限界を超えられませんでした。

閉校と亡命

1933年、ナチスが政権を握ると、バウハウスは「退廃芸術」「ボリシェヴィズムの温床」として攻撃されます。ゲシュタポが学校を閉鎖し、最終的に校側が解散を決定します。

教師と学生は、世界各地に亡命します。

  • グロピウス、ブロイヤー：アメリカ。ハーバード大学。
  • ミース：シカゴ。IIT。
  • モホイ＝ナジ：シカゴ。ニュー・バウハウス（後のIITデザイン学部）。
  • バイヤー：アスペン。
  • アルバース：ブラック・マウンテン・カレッジ、イェール。
  • テル・アビブ：ユダヤ人建築家たちが、ホワイト・シティ（約4000棟のバウハウス/インターナショナル・スタイル建築）を建設。2003年、UNESCO世界遺産。

バウハウスは、学校としては14年しか続きませんでしたが、世界のデザイン教育、建築、タイポグラフィ、家具、グラフィックに計り知れない影響を与えました。

ヴフテマス ― ロシアのもう一つのバウハウス

ヴフテマス（Vkhutemas）は、1920年にモスクワで設立された、ロシアの国立高等芸術技術工房です。1920年から1930年まで存続しました。

  • 目的：芸術と産業の統合。労働者階級のためのデザイナー養成。
  • 教育：基礎課程（色彩、形態、構成）、工房（金属、木工、織物、印刷、建築）。
  • 構成主義：ロトチェンコ、ポポヴァ、ステパノワ、リシツキー。
  • 建築：メルニコフ、ヴェスニン兄弟。
  • 閉鎖：1930年、スターリン体制のなかで解散。社会主義リアリズムへ。

ヴフテマスは、バウハウスと並ぶ、「芸術と技術の統合」の実験でした。しかし、西側では長く忘れられ、バウハウスの影に隠れていました。近年、その重要性が見直されています。

赤ちゃんでもわかる一言
バウハウスには、ロシアに「兄弟」がいました。それがヴフテマスです。同じ理想を抱え、同じように政治に翻弄されました。

デ・ステイル ― 直線と原色の宇宙

デ・ステイル（De Stijl）は、1917年にオランダで結成された芸術運動です。中心人物は、ピート・モンドリアン、テオ・ファン・ドゥースブルフ、ヘリット・リートフェルト。

  • 新造形主義（Nieuwe Beelding）：直線、矩形、原色（赤、青、黄）、無彩色（白、黒、灰）。
  • 普遍性：個人的な感情を排し、宇宙の秩序を表現する。
  • 建築：リートフェルトのシュレーダー邸（1924年）。可動間仕切り、色面、直線。
  • 雑誌『デ・ステイル』：1917〜1932年。
  • 解散：1931年、ファン・ドゥースブルフの死後。

デ・ステイルは、「美術とデザインと建築を、一つの抽象言語で統一する」試みでした。その影響は、バウハウス、グラフィックデザイン、家具、建築に及びます。

アール・デコ ― 機械の豪華さ

アール・デコは、1920〜30年代の装飾様式です。名前は、1925年のパリ万国装飾美術博覧会（Exposition Internationale des Arts Décoratifs et Industriels Modernes）に由来します（「アール・デコ」という言葉は、1960年代に定着）。

  • 特徴：幾何学的な装飾、金属、鏡、漆、貴石、強い色彩、エキゾチシズム。
  • 建築：クライスラー・ビル（1930年、ニューヨーク）、エンパイア・ステート・ビル（1931年）。
  • プロダクト：豪華な家具、時計、香水瓶、汽車、客船。
  • グラフィック：ポスター、雑誌、ファッション。
  • 背景：ジャズ・エイジ、消費文化、植民地のモチーフ、機械時代の楽観。

アール・デコは、「機械時代の豪華さ」を表現しました。金属の輝き、幾何学のリズム、異国情緒。しかし、その「エキゾチック」なモチーフは、しばしば植民地の文化を消費するものでした。

インターナショナル・スタイル ― 世界を白くする

1932年、ニューヨーク近代美術館（MoMA）で、「インターナショナル・スタイル」展が開かれます。キュレーターは、ヘンリー＝ラッセル・ヒッチコックとフィリップ・ジョンソン。

  • 特徴：ボリューム（量塊ではなく空間）、規則性（軸対称ではなく均等）、装飾の排除、ガラス・鋼・コンクリート。
  • 建築家：ル・コルビュジエ、ミース、グロピウス、J.J.P. オウト、リチャード・ノイトラ。
  • CIAM（1928年）：近代建築国際会議。都市計画の国際的な議論。
  • ル・コルビュジエ：『輝く都市』（1935年）、ユニテ・ダビタシオン（1952年、マルセイユ）。「住宅は住むための機械である」。
  • ミース：「Less is more」。

インターナショナル・スタイルは、「近代建築の普遍言語」を主張しました。白い壁、平らな屋根、大きな窓、開放的な間取り。しかし、気候、文化、生活様式の違いを無視し、しばしば失敗しました。熱帯の国でガラスの箱を作れば、灼熱の温室になります。寒い国で薄い壁を作れば、凍えます。普遍の名の下の地方無視は、モダニズムの大きな問題でした。

モダニズムの光と影

モダニズムは、何を達成し、何を失ったのでしょうか。

達成したこと： - 大量生産と標準化による、安価で良質な製品。 - デザインの教育と職業の確立。 - 機能主義、人間工学、色彩理論の進展。 - 社会住宅、公共建築、都市計画の理念。 - グラフィックデザイン、タイポグラフィ、写真の革新。 - 女性、移民、亡命者が世界に広げたネットワーク。

失ったこと： - 地域の伝統、職人の知識、装飾の意味。 - 気候、風土、生活様式への適応。 - 人間の感情、遊び、過剰、不完全さ。 - 植民地の文化を「プリミティブ」と見なすまなざし。 - 社会住宅の画一化、コミュニティの破壊。 - 標準化による排除（障がい者、高齢者、少数民族）。

歴史の教訓
モダニズムは、一つの様式ではない。
機械、社会、普遍、新しい人間についての、さまざまな思想の集合である。
それは、解放と抑圧を同時に生んだ。
安価な住宅、良いデザイン、教育の民主化。
一方で、地域の知恵、装飾の意味、身体の多様性を削った。
モダニズムを評価するときは、両方を同時に見なければならない。

第III部 デザインの世紀

第7章 戦後のデザイン ― 冷戦・消費・革命

13,130 CHARACTERS約 26 分

焼け跡からの出発

1945年、第二次世界大戦が終わります。ヨーロッパと日本は焼け野原になり、アメリカは圧倒的な工業力を持つ唯一の大国になります。戦後のデザインは、復興、消費、冷戦、脱植民地化という四つの力のなかで展開します。

  • 復興：住宅、家具、家電、交通、公共施設の需要。
  • 消費：ベビーブーム、郊外化、テレビ、広告、クレジット。
  • 冷戦：アメリカとソ連の体制競争。デザインは「自由と豊かさ」の宣伝になる。
  • 脱植民地化：アジア・アフリカの独立。先進国のデザインが「開発」の名で輸出される。

赤ちゃんでもわかる一言
戦後のデザインは、「壊れた世界を作り直す」ことから始まりました。そして、作ったものを「誰に売るか」が、次の大きな問題になりました。

アメリカ ― 良い生活のデザイン

イームズ ― 快適さの工学

チャールズ・イームズ（1907〜1978）とレイ・イームズ（1912〜1988）は、戦後アメリカを代表するデザイナーです。

  • 合板の成形：戦時中の軍用副木（splint）の技術を、家具に転用。LCW（1946年）、DCM。
  • グラスファイバー：プラスチックの一体成形。DAX、DAR（1948年）。
  • ラウンジチェア（1956年）：3枚の合板、革、アルミ。快適さと高級感。
  • アルミニウム・グループ（1958年）：オフィス家具。
  • 『パワーズ・オブ・テン』（1977年）：10の24乗から10の-16乗まで、宇宙のスケールを映像で見せる。

イームズのデザインは、「素材の可能性を徹底的に探求し、人間の体に合わせる」という姿勢に貫かれています。チャールズの言葉に、次のものがあります。

「細部は細部ではない。細部がデザインそのものだ。」

イームズは、デザインを「問題解決」と「遊び」の両方として捉えていました。椅子、玩具、映画、展示、教育。境界を越える自由さが、彼らの魅力です。

ドレイフス ― 人間を測る

ヘンリー・ドレイフス（1904〜1972）は、『人のためのデザイン』（1955年）で、人間工学と人体計測をデザインの中心に置きました。

  • ジョンとジョセフィン：平均的な男性・女性の人体チャート。製品の寸法を決める基準。
  • ベル・テレフォン：電話機のデザイン。受話器の形、ダイヤルの位置、色。
  • ハネウェル・サーモスタット：丸い温度調節器。使いやすさと美しさ。
  • 鉄道、航空機、農機具：幅広い産業デザイン。

ドレイフスは、「デザインは、人間の身体と心理を測ることから始まる」ことを示しました。ただし、平均人体モデルは、平均から外れる人（子ども、高齢者、障がい者、女性）を排除する危険もあります。この問題は、後のインクルーシブ・デザインにつながります。

コーポレート・アイデンティティ ― 企業の顔

1950〜60年代、アメリカの企業は、コーポレート・アイデンティティ（CI）を重視します。

  • IBM：ポール・ランドのロゴ（1956年）、エリオット・ノイズのデザイン・プログラム。建築、製品、グラフィックの統一。
  • CBS：ウィリアム・ゴールデンの「目」のロゴ（1951年）、ルー・ドーフスマンの広告。
  • ウェスティングハウス：ランドのロゴ。
  • コンテナ・コーポレーション・オブ・アメリカ：ランドのポスター。
  • GM：ハーレー・アールのスタイリング。モトラマ（1949年）、テールフィン。

CIは、「企業を一つの人格として見せる」装置です。ロゴ、色、書体、建築、製品、広告。すべてが同じ言語で語ることで、信頼と記憶を作ります。同時に、CIは企業の権力を自然に見せる、イデオロギー的な装置でもあります。

ソ連・東欧 ― もう一つの戦後デザイン

冷戦のもう一方の側でも、デザインは国家の計画と密接に結びついていました。

  • ソ連：1962年、全連邦技術美学研究所（VNIITE）設立。家電、家具、輸送、都市環境の設計を研究。スプートニク1号（1957年）、ガガーリン（1961年）の宇宙競争は、技術とデザインのプロパガンダになった。国家規格（GOST）が品質を規定。
  • 東ドイツ：バウハウスの遺産を継ぎ、Formgestaltung（形の創造）を国家が組織。化学工業、家電、家具。
  • チェコスロバキア：スコダ、ガラス、アニメーション。1958年ブリュッセル万博の「ブラッセル・スタイル」。
  • ポーランド：ポスター・スクール（ヘンリク・トマシェフスキ、ロマン・チェシヴィッチ）。検閲のなかで、比喩とユーモアを使ったグラフィック。
  • ユーゴスラビア：独自の市場社会主義。工業デザイン、家具、建築。

計画経済のデザインは、大量生産の能力と、消費者の選択肢の少なさという矛盾を抱えていました。品質、修理、素材の制約。1989年以降、東欧は市場経済に移行し、西側ブランドと地元デザインの混交が進みます。

赤ちゃんでもわかる一言
冷戦のデザインは、アメリカ対ソ連の二択ではありません。ソ連・東欧にも、国家の計画のなかで、独自のデザイン文化がありました。

ドイツ ― ウルムとブラウン

ウルム造形大学

1953年、ウルム造形大学（HfG Ulm）が設立されます。創設者は、マックス・ビル、インゲ・アイヒャー＝ショル、オトル・アイヒャー。バウハウスの伝統を継ぎながら、より科学技術と社会に開かれたデザイン教育を目指しました。

  • マックス・ビル（1953〜56）：バウハウス的な基礎教育。数学、幾何学、色彩。
  • トマス・マルドナド（1956〜66）：科学技術、記号論、システム論、人間工学を導入。
  • オトル・アイヒャー：グラフィック、ピクトグラム。1972年ミュンヘン五輪の視覚システム。
  • ブラウンとの協力：学生と教員が、ブラウンの製品開発に関わる。
  • 閉校：1968年。財政難、政治的对立、学生運動。

ウルムは、「デザインを芸術から科学へ」移行させる試みでした。記号論、人間工学、システム分析、社会学。デザインは、直感や美意識だけでなく、方法と検証を持つべきだという思想です。この思想は、後のデザイン方法論、デザイン思考、UXデザインに影響を与えます。

ブラウンとディーター・ラムズ

ブラウンは、1921年にドイツで創業した電機メーカーです。1955年、ディーター・ラムズ（1932〜）が入社し、1961年にデザイン部門の責任者になります。

  • SK4（1956年）：ラジオとレコードプレーヤーの一体型。通称「白雪姫の棺」。ガラスと金属の透明な蓋。
  • T3（1958年）：ポケットラジオ。小ささと操作性。
  • ET66（1987年）：計算機。丸いボタン、明確な色分け。
  • 606（1960年）：Vitsoeの棚システム。モジュール式、長寿命。
  • 10の原則：1970年代末に提唱。

ラムズの10原則は、次の通りです（Vitsoeの公式英語版を要約）。

  1. 良いデザインは革新的である。
  2. 良いデザインは製品を有用にする。
  3. 良いデザインは美的である。
  4. 良いデザインは製品を理解可能にする。
  5. 良いデザインは控えめである。
  6. 良いデザインは正直である。
  7. 良いデザインは長持ちする。
  8. 良いデザインは最後の細部まで徹底している。
  9. 良いデザインは環境に優しい。
  10. 良いデザインは、できるだけ少ないデザインである。

赤ちゃんでもわかる一言
ラムズは「良いデザインは、できるだけ少ないデザイン」と言いました。これは「何もデザインしない」という意味ではありません。余分なものを削り、本質だけを残すという意味です。

ラムズの思想は、機能主義、簡素、誠実、長寿命、環境を柱としています。特に「控えめ」「正直」「長持ち」は、現代のサステナブルデザインにも通じます。一方で、ラムズの美学は、ドイツの機能主義とブラウンの企業文化に強く規定されており、普遍的な「良いデザイン」ではありません。白と灰色の箱が、すべての文化に合うわけではないのです。

一歩深く（専門家向け）
ラムズの10原則は、しばしば「永遠の真理」のように引用されますが、歴史的には1970年代末の消費社会への危機感から生まれました。ラムズ自身、「形、色、音の耐え難い混乱」に悩み、自分自身もその混乱に加担していると感じていました。10原則は、普遍的な美学というより、「デザイナーの倫理」の宣言です。また、第9原則「環境に優しい」は、当時としては先駆的ですが、ブラウンの実際の製品がどこまで環境負荷を減らしたかは、別の検証が必要です。

イタリア ― デザインを文化にする

オリベッティ ― 工場と文化

オリベッティは、1908年にイタリアのイヴレアで創業した、タイプライターと計算機の会社です。アドリアーノ・オリベッティ（1901〜1960）は、1938年に経営を引き継ぎ、デザインと社会改革を結びつけました。

  • レテラ22（1950年）：マルチェロ・ニッツォーリ設計。軽く、美しいタイプライター。
  • プログラマ101（1965年）：世界初の商用デスクトップ電卓の一つ。ピエール・ジョルジョ・ペロット設計。
  • ヴァレンタイン（1969年）：エットーレ・ソットサス設計。赤い携帯用タイプライター。デザインのアイコン。
  • 企業文化：工場の周りに住宅、学校、図書館、医療施設。デザインは、製品だけでなく、労働と生活の質を含む。

オリベッティは、「デザインは企業文化である」ことを示しました。製品の美しさは、労働者の尊厳、地域の文化、経営の哲学と切り離せません。

イタリアン・デザインの黄金時代

1950〜60年代、イタリアは「デザインの国」としての地位を確立します。

  • ヴェスパ（1946年）：コッラディーノ・ダスカーニオ設計。スクーター。戦後の移動の民主化。
  • ランブレッタ（1947年）：イノチェンティ。
  • トリエンナーレ：ミラノのデザイン展。1950〜60年代に国際的な影響。
  • カスティリオーニ兄弟：アルコ・ランプ（1962年）、スヌーピー・ランプ（1967年）。遊びと技術。
  • マルコ・ザヌーソ：レディ・チェア（1951年）。家具と工業生産。
  • リチャード・サッパー：ティツィオ・ランプ（1972年）。可動式の作業灯。
  • ジョー・コロンボ：ウニヴェルサレ・チェア（1965年）。プラスチックの一体成形。
  • エンツォ・マーリ：『Autoprogettazione』（1974年）。誰でも作れる家具の設計図。教育と批判的デザイン。

イタリアのデザインは、「美しさは機能の一部である」という信念に支えられています。自動車、家具、照明、キッチン、ファッション。デザインは、日常の文化そのものです。

ラディカル・デザインと反デザイン

1960年代末、イタリアでラディカル・デザインが起こります。

  • スーパースタジオ（1966年）：『連続するモニュメント』（1969年）。地球を覆う巨大なガラスの壁。ユートピアとディストピア。
  • アルキズーム（1966年）：『ノーストップ・シティ』（1970年）。無限に続く都市。消費社会の批判。
  • UFO、グルッポ・999、ストゥルメンティ。
  • メンフィス（1980〜87年）：エットーレ・ソットサス。色、模様、プラスチックラミネート。機能主義への反逆。

ラディカル・デザインは、「デザインは問題を解くだけでなく、問題を提起する」ことを示しました。売れる製品を作るのではなく、都市、消費、政治、環境についての問いを、オブジェクトや図面で提示します。この姿勢は、後の批判的デザイン、スペキュラティブ・デザイン、デザイン・フィクションに受け継がれます。

スカンジナビア ― 民主的デザイン

1950年代、デンマーク、スウェーデン、フィンランド、ノルウェーのデザインが、世界で注目されます。

  • フィン・ユール（1912〜1989）：有機的な曲線、木の温もり。
  • ハンス・ウェグナー（1914〜2007）：ウィッシュボーン・チェア（1949年）、ラウンド・チェア（1949年）。職人の技と量産のバランス。
  • アルネ・ヤコブセン（1902〜1971）：アント・チェア（1952年）、セブン・チェア（1955年）、エッグ・チェア（1958年）、スワン・チェア（1958年）。
  • アルヴァ・アールト（1898〜1976）：パイミオ・チェア（1933年）、サヴォイ・ベース（1936年）。曲げ木。
  • IKEA（1943年）：flat-pack（1956年）、民主的価格、北欧デザインの世界化。

「スカンジナビアン・デザイン」は、「民主的で、人道的で、自然素材で、美しい」というイメージで売られました。1954〜57年のアメリカ巡回展「Design in Scandinavia」が、そのイメージを決定づけます。

しかし、このイメージには神話もあります。北欧のデザインは、福祉国家、高い税、強い労働組合、職人教育、森林資源という、特定の社会条件の上に成り立っています。他の国がその表面だけを真似ても、同じ結果にはなりません。また、北欧のデザインも、植民地主義、資源輸出、社会保障の排除と無関係ではありません。

日本 ― 戦後の奇跡（詳細は第10章）

日本の戦後デザインは、「技術と美の統合」を独自に発展させました。

  • ソニー：1955年、TR-55トランジスタラジオ。1958年、ソニーに改名。1979年、ウォークマン。
  • ホンダ：スーパーカブ（1958年）。世界で最も売れた乗り物。
  • トヨタ：カローラ（1966年）、生産方式（TPS）。
  • 1964年東京オリンピック：亀倉雄策のエンブレム、勝見勝らのピクトグラム。日本のグラフィックデザインが世界に知られる。
  • 1970年大阪万博：丹下健三のマスタープラン、岡本太郎の太陽の塔。デザインと国家のショーケース。
  • 無印良品（1980年）：無印・良品。素材と機能の最小限。

日本については、第10章で詳しく扱います。

20世紀の非西洋デザイン ― 複数の近代

戦後のデザイン史は、欧米と日本だけの物語ではありません。アジア、アフリカ、ラテンアメリカ、中東でも、独自の近代化とデザインの実験が進みました。

インド ― 手工芸と工業のあいだ

1947年の独立後、インドは「手工芸を守ること」と「工業化すること」のあいだで揺れました。国立デザイン学院（NID）は1961年、アーメダバードに設立されます。背景には、ジャワハルラール・ネルー首相の支援と、チャールズ＆レイ・イームズの提言（1958年）がありました。NIDは、農村の道具、陶器、織物、家具、グラフィック、工業製品を横断する教育を目指しました。

  • 手工芸：カディ（手紡ぎ・手織りの布）、陶器、竹細工、真鍮。ガンディーのチャルカは、政治とデザインの象徴。
  • 工業：自動車、家電、IT。1991年の経済自由化以降、ベンガルールのIT産業、タタ、マヒンドラ。
  • デザイン教育：NID、IIT（インディアン・インスティテュート・オブ・テクノロジー）のデザイン学科。
  • 課題：農村と都市、手工芸と大量生産、グローバル市場と地域文化。
ブラジル ― 熱帯のモダニズム

ブラジルは、20世紀半ばに、独自のモダニズムを発展させます。ブラジリア（1956〜60年、ルシオ・コスタの都市計画、オスカー・ニーマイヤーの建築）は、近代都市計画の実験です。家具では、ジョアキン・テンレイロ、セルジオ・ロドリゲスが、ブラジル材と職人技を活かしました。

  • ブラジリア：幾何学、軸線、公共建築。自動車中心の都市計画は、後に批判されます。
  • 家具：ジャカランダ、ローズウッド、革。曲線と軽さ。
  • 現代：カンパナ兄弟（廃材、ぬいぐるみ、混沌）、ハヴァイアナス（ゴムサンダル）。
  • 課題：格差、都市のスプロール、アマゾンの森林破壊。
メキシコ ― 革命と展示

メキシコは、1910年の革命後、壁画運動、考古学、デザインを結びつけます。ペドロ・ラミレス・バスケスは、国立人類学博物館（1964年）、アステカスタジアム（1968年）を設計しました。クララ・ポルセットは、バウハウスの影響を受けながら、メキシコの素材と職人技で家具をデザインしました。

  • 国立人類学博物館：先住文化の展示と建築の統合。
  • オリンピック1968：グラフィック・アイデンティティの革新。
  • 課題：先住文化の表象、観光、都市化。
中国 ― 世界の工場から、デザインの国へ

1949年の新中国成立後、中国はソ連の工業モデルを導入します。1978年の改革開放以降、深圳などの経済特区が作られ、OEM（相手先ブランドによる生産）で世界の工場になります。2010年代以降、小米（シャオミ）、華為（ファーウェイ）、アリババ、テンセントなどが、独自のデザインとブランドを展開します。

  • 製造：家電、スマホ、EV、太陽光パネル、電池。
  • デザイン教育：中央美術学院、清華大学美術学院、同済大学。
  • イベント：2008年北京オリンピック、2010年上海万博。
  • 課題：模倣から創造への移行、労働条件、環境、地政学。
韓国 ― 国家戦略としてのデザイン

韓国は、戦後、政府主導でデザイン振興を進めます。三星（サムスン）、LG、現代（ヒュンダイ）は、品質とデザインで世界市場に進出しました。1988年のソウルオリンピックは、韓国デザインのショーケースになります。

  • 電子機器：スマホ、テレビ、家電。
  • 自動車：ヒュンダイ、起亜。
  • 文化：K-POP、ドラマ、ゲーム、コスメ。
  • 課題：財閥依存、労働、北朝鮮との緊張。
中東 ― 石油後のデザイン

湾岸諸国は、石油収入を使って、建築と都市の巨大プロジェクトを進めます。

  • ドバイ：ブルジュ・ハリファ（2010年）、人工島、巨大ショッピングモール。
  • アブダビ：ルーヴル・アブダビ（2017年、ジャン・ヌーヴェル）。
  • カタール：イスラーム美術博物館（2008年、I.M.ペイ）、ワールドカップ2022。
  • マスダール・シティ：持続可能な都市の実験（2008年〜）。
  • 課題：移民労働、水、冷房、気候、文化の観光化。
アフリカ ― モバイルとデザイン

アフリカは、20世紀後半、植民地支配からの独立、紛争、債務、構造調整を経て、21世紀に成長します。

  • M-Pesa（2007年、ケニア）：携帯電話による送金。銀行口座を持たない人々に金融サービスを提供。
  • デヴィッド・アジャイ：建築。国立アフリカ系アメリカ人歴史文化博物館（2016年、ワシントンDC）。
  • ファッション：ラゴスのファッションウィーク、アンカラ、ケンテ。
  • デザイン教育：ケープタウン、ナイロビ、ラゴス。
  • 課題：電力、水、教育、雇用、紛争、気候。
東南アジア ― 手工芸と都市化

東南アジアは、多様な民族、宗教、言語、素材を持つ地域です。植民地支配、独立、経済成長、観光、都市化のなかで、独自のデザインが生まれました。

  • インドネシア：バティック（ろうけつ染め、UNESCO無形文化遺産2009年）、ラタン、竹、ジャワの建築。首都ジャカルタの都市問題。
  • タイ：シルク、セラミック、仏教建築、バンコクのデザイン・シーン。
  • ベトナム：漆、竹、ラッカー、バイク文化、ホイアンの町並み。
  • シンガポール：HDB（公共住宅）、都市計画、ガーデンズ・バイ・ザ・ベイ（2012年）。国家主導の都市デザイン。
  • フィリピン：織物、籐、マニラの都市文化。

東南アジアのデザインは、手工芸の伝統と、急速な都市化・観光・グローバル生産のあいだで、独特の緊張を抱えています。

赤ちゃんでもわかる一言
戦後のデザインは、欧米と日本だけのものではありません。インド、ブラジル、中国、韓国、中東、アフリカ、東南アジアでも、それぞれの歴史と素材に合わせたデザインが生まれました。

一歩深く（専門家向け）
「非西洋」という言葉自体が、西洋を基準にした分類です。本書では便宜的に使いますが、実際には、複数の近代があり、それぞれが西洋の技術を選択的に取り入れ、地域の文化と混ぜています。これを「複数の近代（multiple modernities）」と呼びます。デザイン史の課題は、西洋の影響を無視することではなく、それぞれの地域の主体性と創造性を、正確に記述することです。

グラフィックデザインの世紀 ― 文字とイメージの戦争

20世紀のグラフィックデザインは、ポスター、雑誌、広告、企業の顔、公共の情報を担う、巨大な産業になりました。

  • ポスター：カッサンドル（『ノルマンディー号』1935年）、ロトチェンコ（本の広告、1924年）、ハートフィールド（反ナチスのフォトモンタージュ）、モホイ＝ナジ（バウハウスの印刷）。
  • スイス・スタイル：1950年代。ミュラー＝ブロックマン、ホフマン、ルーダー。グリッド、サンセリフ、非対称、客観性。ヘルベチカ（1957年）はその象徴。
  • アメリカ：ポール・ランド（IBM、ABC）、ソール・バス（映画タイトル、『めまい』1958年）、ミルトン・グレイザー（「I ❤ NY」1977年）、プッシュ・ピン・スタジオ。
  • カウンターカルチャー：サイケデリック・ポスター（ウェス・ウィルソン）、エミグレ（1980年代）、デヴィッド・カーソン（『Ray Gun』1992〜95年）、グランジ、デコンストラクション。読みやすさへの挑戦。
  • 情報デザイン：アイソタイプ（ノイラート、1925〜34年）、ピクトグラム（東京1964、ミュンヘン1972）、タフテ（1983年）、ウェイファインディング。
  • 世界：キューバのポスター（1960年代）、ポーランドのポスター（1950〜80年代）、日本のグラフィック（亀倉雄策、田中一光、横尾忠則、福田繁雄）、イランのグラフィック。
  • デジタル：モーション・グラフィックス、可変フォント、デザインシステム。

グラフィックデザインは、情報を見えるようにし、主張を説得力あるものにする技術です。地図、標識、選挙ポスター、パッケージ、UI。それは中立ではなく、何を見せ、何を隠すかという選択です。

ファッション ― 身体のデザイン

ファッションは、最も身近なデザインです。衣服は、身体を包み、守り、社会との関係を調整します。

  • オートクチュール：チャールズ・フレデリック・ワース（1858年、パリ）。デザイナーが作者になり、季節ごとのコレクションとファッションショーを作る。
  • ココ・シャネル：1910〜20年代。ジャージー、リトル・ブラック・ドレス、シャネルNo.5（1921年）。女性の身体を自由にする。
  • クリスチャン・ディオール：1947年「ニュールック」。くびれとボリューム。戦後の女性らしさの再定義。
  • イヴ・サンローラン：1958年、トラペーズ。1966年、女性用タキシード（ル・スモーキング）。ジェンダーの境界を揺らす。
  • クール・レジュ、ピエール・カルダン：1960年代、スペース・エイジ。未来主義。
  • 日本：1970年、ケンゾー・タカダ。1971年、イッセイミヤケ。1981年、山本耀司、コム・デ・ギャルソン。黒、布の塊、非対称。
  • ベルギー：アントワープ・シックス（1986年）、マルタン・マルジェラ（1989年）。デコンストラクション、古着、匿名性。
  • イギリス：マリー・クワント（ミニスカート、1960年代）、ヴィヴィアン・ウェストウッド（パンク、1970年代）、アレキサンダー・マックイーン（1990年代）。
  • イタリア：ジョルジオ・アルマーニ（1975年、ソフト・テーラリング）、プラダ（1913年、ミウッチャ・プラダが1970〜80年代に変革）、ヴェルサーチ。
  • アメリカ：リーバイス501（1873年）、スポーツウェア、ラルフ・ローレン、ドナ・カラン。
  • ファストファッション：ZARA（1975年）、H&M（1947年）、ユニクロ（1984年）、SHEIN（2008年）。安さと速さの一方で、労働、環境、大量廃棄の問題。

ファッションは、身体と社会の関係を設計する仕事です。ジェンダー、階級、年齢、人種、宗教。何を着られるか、何を着ることを許されるか。サイズの包摂、修理、リセール、デジタルファッションも、これからの重要なテーマです。

赤ちゃんでもわかる一言
服は、ただの布ではありません。「私はこういう人間です」と社会に伝える、最も身近なデザインです。

ポップと反デザイン ― 消費社会の鏡

1950〜60年代、消費社会が成熟すると、デザインはポップ・アートと結びつきます。

  • アンディ・ウォーホル：キャンベル・スープ缶、ブリロ・ボックス。大量生産と広告の記号。
  • リチャード・ハミルトン：『一体何が、今日の家庭をこれほど違い、魅力的にしているのか？』（1956年）。消費社会のコラージュ。
  • ピエロ・フォルナセッティ：装飾的な家具、パターン。
  • ヴェルナー・パントン：ファンタジー・ランドスケープ、プラスチックの椅子。

ポップは、「消費社会を批判するのか、それとも肯定するのか」という問いを立てます。ウォーホルは、商業と芸術の境界を溶かしました。デザインもまた、商業と批判のあいだで揺れます。

ポストモダン ― 「Less is a bore」

1970年代、モダニズムへの反動としてポストモダンが起こります。

  • ロバート・ヴェンチューリ：『建築における複雑性と矛盾』（1966年）。「Less is a bore（少ないことは退屈だ）」。
  • ヴェンチューリ、スコット・ブラウン、アイゼナワー：『ラスベガスから学ぶ』（1972年）。商業建築、看板、駐車場、高速道路。日常の景観を建築の教材にする。
  • チャールズ・ジェンクス：『ポストモダン建築の言語』（1977年）。
  • マイケル・グレイブス：ポートランド・ビル（1982年）。
  • ジェームズ・スターリング：シュトゥットガルト新州立美術館（1984年）。
  • メンフィス（1980〜87年）：色、模様、引用、アイロニー。

ポストモダンは、「モダニズムの普遍性、機能主義、禁欲主義を疑う」運動です。歴史、文脈、装飾、遊び、意味を復権します。同時に、商業主義、表層性、冷笑主義に陥る危険もあります。

一歩深く（専門家向け）
ポストモダンは、建築・デザイン・哲学・文学で、異なる意味を持ちます。建築では、ジェンクスの「ダブル・コーディング」（専門家と大衆の両方に読める）が重要です。哲学では、リオタールの「大きな物語の終焉」が有名ですが、デザインとの関係は間接的です。ポストモダン・デザインを「装飾の復権」とだけ理解すると、その政治的・認識論的な挑戦を見失います。

都市と建築 ― 生活の容器

都市は、人類が作った最大のデザインです。20世紀の都市計画は、近代建築の理念と、その失敗の歴史でもあります。

  • CIAM（1928年）：近代建築国際会議。都市を、住居・仕事・娯楽・交通の四機能に分ける。
  • アテネ憲章（1933年）：機能主義的城市計画。ゾーニング、高層住宅、自動車優先。
  • ル・コルビュジエ：『輝く都市』（1935年）。公園のなかの高層棟。太陽、空間、緑。
  • 批判：ジェイン・ジェイコブズ『アメリカ大都市の死と生』（1961年）。混合用途、歩道、街路の目、コミュニティ。ケビン・リンチ『都市のイメージ』（1960年）。道、端、地区、結節点、ランドマーク。ヤン・ゲール『屋外空間の生活』（1971年）。人が集まる場所の条件。
  • ニューアーバニズム（1993年）：Walkable、mixed-use、transit-oriented。Seaside（フロリダ）など。
  • 現代：タクティカル・アーバニズム（2012年）、15分都市（カルロス・モレノ、2016年）、スーパーブロック（バルセロナ、2016年）、サイクリング、公共空間、気候適応。

都市は、人の行動、健康、不平等を形づくります。道路の幅、公園の位置、公共交通の料金、日陰の量。これらは、政治的な選択です。良い都市は、美しいだけでなく、歩きやすく、安全で、多様な人が出会える都市です。

パパネック ― デザインの良心

ヴィクター・パパネック（1923〜1998）は、1971年に『リアル・ワールドのためのデザイン』を出版します。冒頭は、こうです。

「工業デザインより有害な職業は、そう多くない。」

パパネックは、デザインが「浪費、搾取、環境破壊、社会的無責任」に加担していると批判しました。そして、「本当に必要なのは、贅沢品ではなく、生活の基本を満たすデザインだ」と主張します。

  • 適正技術（appropriate technology）：地域の資源、技能、文化に合った技術。
  • 障がい者のためのデザイン：パパネックは、障害のある人のための道具を多数設計。
  • 「他の90%のためのデザイン」：世界人口の大多数が、先進国のデザインの恩恵を受けていない。
  • 教育：学生に、社会の問題を解決するプロジェクトを課す。

パパネックは、しばしば「理想主義者」「説教者」と批判されます。しかし、彼の問題提起は、サステナブルデザイン、インクルーシブ・デザイン、デザイン・ジャスティスの先駆けでした。

オイルショック ― 限界の認識

1973年と1979年のオイルショックは、大量生産・大量消費の前提を揺るがします。

  • ローマクラブ『成長の限界』（1972年）：資源、人口、環境の限界を警告。
  • シューマッハ『スモール・イズ・ビューティフル』（1973年）：適正規模、地域経済、人道的技術。
  • 日本の省エネ製品：小型車、省電力家電。品質管理と生産性。
  • 環境運動：公害、大気汚染、水質汚濁、森林破壊。
  • デザインの反省：使い捨て、計画的陳腐化、過剰包装。

オイルショックは、「デザインは、無限の成長を前提にできない」ことを教えました。この認識は、1990年代の環境デザイン、2000年代のサステナブルデザイン、2010年代のサーキュラー・エコノミーへと続きます。

コンピュータとの出会い

デジタルデザインの歴史は、コンピュータの歴史と重なります。しかし、最初から「使いやすい画面」があったわけではありません。コンピュータは、まず計算機であり、専門家の道具でした。それを「誰でも使えるもの」に変えたのが、デザインの仕事です。

  • ヴァネヴァー・ブッシュ『As We May Think』（1945年）：情報の爆発に対処する、記憶拡張装置「Memex」の構想。
  • J.C.R. リックライダー『Man-Computer Symbiosis』（1960年）：人間とコンピュータの協働。
  • アイヴァン・サザーランド『Sketchpad』（1963年）：初の対話型グラフィックス・システム。ペンで図を描き、コンピュータが形を操作する。
  • ダグラス・エンゲルバート「The Mother of All Demos」（1968年）：マウス、ウィンドウ、ハイパーテキスト、ビデオ会議、共同編集。現在のパソコンの原型を、一度に披露。
  • ゼロックス・パロアルト研究所（PARC）：1970年代に、Alto（1973年）、GUI、マウス、ビットマップ・ディスプレイ、Ethernet、レーザープリンタを開発。

赤ちゃんでもわかる一言
コンピュータは、もともと計算機でした。それを「絵を描き、文を書き、人とつながる機械」に変えたのが、デジタルデザインの始まりです。

アップル ― デザインを統合する

アップルは、1976年にスティーブ・ジョブズとスティーブ・ウォズニアックが設立します。

  • Apple II（1977年）：個人向けパソコンの普及。
  • Lisa（1983年）：GUI、マウス。商業的には失敗。
  • Macintosh（1984年）：GUIの大衆化。「1984」のCM。使いやすさとデザインの統合。
  • iMac（1998年）：半透明のボディ、一体型。デザインの復権。
  • iPod（2001年）：クリックホイール、白いイヤホン。音楽体験の再設計。
  • iPhone（2007年）：マルチタッチ、アプリ、モバイル・インターネット。
  • App Store（2008年）：ソフトウェアの流通を再設計。
  • iPad（2010年）、Apple Watch（2015年）、Vision Pro（2024年）：空間コンピューティング。

アップルのデザインは、「ハードウェア、ソフトウェア、サービス、コンテンツを統合する」ことに強みがあります。ジョナサン・アイヴ（1992年入社）は、ラムズの影響を公言し、素材、曲線、削り出し、パッケージまでこだわりました。

ただし、アップルがGUIやスマートフォンを「発明」したわけではありません。GUIはPARCとエンゲルバート、スマートフォンは多数の先行技術（PDA、携帯電話、タッチスクリーン、iPod）の融合です。アップルの貢献は、「技術を、使いやすく、美しく、一つの体験に統合した」ことです。

一歩深く（専門家向け）
アップルの「デザイン主導」は、しばしば「天才の直感」と語られますが、実際には、素材の試作、人間工学、サプライチェーン、ソフトウェア工学、マーケティングの巨大な組織能力に支えられています。また、閉鎖的なエコシステムは、使いやすさと引き換えに、修理、拡張、競争を制限します。デザインの美しさと、ユーザーの自由は、しばしば緊張関係にあります。

ウェブ ― 誰でも発信できる

1989年、ティム・バーナーズ＝リーがCERNでウェブを発明します。1991年に公開。1993年、Mosaicブラウザ。1994年、Netscape。1998年、Google。

  • HTML：文書の構造を記述する言語。
  • CSS：見た目を分離する言語。
  • JavaScript：動きと対話。
  • URL：資源の住所。
  • HTTP：通信の規格。
  • 検索：情報の見つけ方。
  • ソーシャルメディア：人間関係の設計。
  • レスポンシブ・デザイン（2010年、イーサン・マルコット）：画面サイズに適応するレイアウト。
  • デザインシステム：コンポーネント、トークン、ガイドライン。

ウェブは、「デザインの民主化」をもたらしました。誰でもページを作れ、誰でも世界に発信できます。同時に、「デザインの均質化」も進みました。同じテンプレート、同じフォント、同じレイアウト。プラットフォームのアルゴリズムが、見た目と行動を標準化します。

インタラクション・デザインとUX

1980年代、ビル・モグリッジとビル・バープランクが「インタラクション・デザイン」という言葉を使い始めます。人間とコンピュータの相互作用を、デザインの対象にする分野です。

  • ユーザー中心設計（UCD）：ユーザーのニーズ、能力、文脈を理解して設計する。
  • ユーザビリティ：効率、学習しやすさ、エラーの少なさ、満足度。
  • 情報アーキテクチャ：情報の構造とナビゲーション。
  • インタラクション・デザイン：時間、フィードバック、状態、遷移。
  • UX（ユーザー体験）：ドン・ノーマンが1990年代にAppleで使い始めたとされる。製品単体ではなく、使う前・使う間・使った後の体験全体。

ドン・ノーマンの『誰のためのデザイン？』（1988年）は、デザインの認知心理学を一般に広めました。

  • アフォーダンス：物が提供する行為の可能性。椅子は「座る」をアフォードする。
  • シグニファイア：行為を促す視覚的な手がかり。ドアノブ、ボタン、矢印。
  • マッピング：操作と結果の対応。コンロのつまみと火口の位置。
  • フィードバック：行為の結果を知らせる。音、光、振動。
  • 概念モデル：ユーザーが頭のなかで作る仕組みの理解。

ノーマンは後に「ユーザー中心設計」という言葉を批判的に見直し、「人間中心設計」や「人を中心にしたデザイン」を好むようになります。ユーザーは受動的な存在ではなく、状況のなかで行為する人間だからです。

サービスデザイン ― 見えないものを見せる

サービスデザインは、サービスを、顧客の体験と組織のプロセスの両方から設計する分野です。

  • リン・ショスタック（1982年/1984年）：サービスの設計と管理。サービス・ブループリント。
  • ライブワーク（2001年、ノルウェー）：サービスデザインの実践。
  • 顧客ジャーニー：認知、検討、購入、使用、サポート、解約。
  • タッチポイント：店舗、アプリ、電話、メール、請求書。
  • フロントステージ／バックステージ：顧客に見える部分と、支える組織の部分。
  • 共創：顧客と従業員が、サービスの価値を一緒に作る。

サービスデザインは、「デザインの対象を、モノから関係へ」広げました。病院、銀行、行政、交通、教育。良くも悪くも、サービスは体験の設計です。

デザイン思考 ― 方法か、信仰か

デザイン思考は、デザイナーの思考法を、ビジネスや社会の問題に応用する方法論です。

  • ハーバート・サイモン『人工物の科学』（1969年）：デザインを「問題解決の科学」として位置づける。
  • ホルスト・リッテルとメルヴィン・ウェバー（1973年）：「厄介な問題（wicked problems）」。定義が曖昧で、正解がなく、解決が新たな問題を生む問題。
  • ドナルド・ショーン『省察的実践家』（1983年）：専門家は、行為しながら考える。
  • リチャード・ブキャナン（1992年）：「厄介な問題」をデザイン思考で扱う。
  • IDEO（1991年）：デビッド・ケリーらが設立。人間中心、プロトタイピング、多職種チーム。
  • ティム・ブラウン（2008年、Harvard Business Review）：デザイン思考を、人・技術・ビジネスの交点として定義。
  • スタンフォード d.school（2005年）：教育プログラム。
  • ダブル・ダイヤモンド（2004年、Design Council）：発見、定義、開発、提供。
  • デザイン・スプリント（2010年代、Google Ventures）：5日間で問題を検証。

デザイン思考は、「共感、問題定義、アイデア、プロトタイプ、テスト」のプロセスとして普及しました。企業、政府、NGO、教育機関が採用し、デザインの社会的地位を高めました。

しかし、批判もあります。

  • 表面的な共感：ユーザーを理解したつもりになる。
  • 政治の無視：問題の構造、権力、格差を扱わない。
  • 方法の画一化：付箋とホワイトボードの儀式になる。
  • 成果の測定困難：イノベーションの成果をどう測るか。
  • 労働の搾取：デザイナーの長時間労働、低賃金。
  • 「デザイン思考は失敗した」（ブルース・ナスバウム、2011年）。
  • 「デザイン思考は本質的に保守的で、現状を維持する」（ナターシャ・イスカンダー、2018年）。

デザイン思考は、万能薬ではありません。しかし、「ユーザーを中心に置く」「早く試す」「多職種で協働する」という原則は、今も有効です。問題は、方法そのものではなく、誰のための、何のためのデザインかという問いを、省略してしまうことです。

マテリアル・デザインとデザインシステム

2014年、GoogleはMaterial Designを発表します。紙とインクの比喩、影、動き、グリッド、色彩。Android、Web、アプリの統一言語です。

  • Material Design（2014年）：Googleのデザイン言語。
  • Human Interface Guidelines（Apple）：iOS、macOSのガイドライン。
  • Fluent Design（Microsoft）：光、深度、動き、素材。
  • Carbon（IBM）、Polaris（Shopify）、Atlassian Design System。
  • デザイン・トークン：色、文字、間隔、影を、コードとデザインで共有する変数。
  • コンポーネント：ボタン、フォーム、ナビゲーションの再利用可能な部品。
  • アクセシビリティ：コントラスト、フォーカス、スクリーンリーダー、キーボード操作。

デザインシステムは、「デザインをスケールさせる」ための装置です。大企業、多数の製品、世界中のチーム。一貫性、効率、品質、アクセシビリティを支えます。同時に、「創造性の標準化」という危険もあります。すべての製品が同じ見た目になり、地域や文化の違いが無視されるのです。

インターフェースは権力である

デジタルのデザインは、「画面の見た目」だけではありません。何を見せ、何を隠し、何を選びやすくし、何を選びにくくするか。インターフェースは、行動の設計です。

  • ダークパターン：解約を難しくする、追加料金を隠す、同意を誘導する。
  • アテンション・エコノミー：通知、無限スクロール、いいね。注意を奪う設計。
  • パーソナライゼーション：好みに合わせる。同時に、閉じた世界を作る。
  • 監視：行動データ、位置情報、生体情報。
  • アルゴリズム：何が表示されるかを決める。デザインは、コードのなかにある。

赤ちゃんでもわかる一言
画面のデザインは、部屋の設計に似ています。ドアの位置、照明、家具の配置で、人の動きが変わります。デジタルでは、その部屋が毎秒変わり、あなたの行動を記録します。

ゲームとサウンド ― ルールと響きのデザイン

ゲームデザインは、ルール、フィードバック、難易度、報酬、物語を設計する分野です。

  • 初期：『Spacewar!』（1962年）、『Pong』（1972年）、アーケード。
  • 任天堂：宮本茂の『ドンキーコング』（1981年）、『スーパーマリオブラザーズ』（1985年）、『ゼルダの伝説』（1986年）。横井軍平のゲームボーイ（1989年）。
  • 家庭用機：プレイステーション（1994年）、Xbox（2001年）、モバイルゲーム、eスポーツ。
  • 理論：フロー（チクセントミハイ）、アフォーダンス、学習曲線、強化スケジュール、ナラティブ。
  • 課題：依存、暴力、労働、アクセシビリティ、ゲーム化（gamification）の倫理。

サウンドデザインは、製品、映画、ゲーム、空間の音を設計する分野です。

  • 映画：ウォルター・マーチ（『地獄の黙示録』）、ベン・バート（『スター・ウォーズ』）。
  • 製品：電子レンジの「ピッ」、車のドアの閉まる音、EVの走行音。
  • 空間：駅、病院、商業施設のBGMとアナウンス。
  • ブランド：起動音、通知音、コーヒーマシンの音。
  • アクセシビリティ：補聴器、字幕、振動、視覚的な代替。

ゲームとサウンドは、時間と注意をデザインする技術です。何を気持ちよく感じ、何に夢中になり、何を聞き逃すか。それは、UIの見た目以上に、体験の深い層に働きかけます。

2026年のデザイン地図

2026年のデザインは、次の８つの転換のただ中にあります。

  1. モノからシステムへ：製品単体ではなく、サービス、サプライチェーン、制度を設計する。

環境デザインの系譜

  • 1980年代：グリーンデザイン。リサイクル、省エネ、有害物質の削減。
  • 1990年代：エコデザイン。ライフサイクル評価（LCA）、設計段階からの環境配慮。
  • 2000年代：Cradle to Cradle（2002年、マクドノーとブラウングト）。「廃棄物は食物である」。素材を、生物学的循環と技術的循環に分ける。
  • 2010年代：サーキュラー・エコノミー。Ellen MacArthur Foundation。廃棄物を出さない、製品と素材を循環させる、自然を再生する。
  • 2020年代：規制と義務化。EUのエコデザイン規則（ESPR）、修理する権利、デジタル製品パスポート。
サーキュラー・エコノミーの３原則

Ellen MacArthur Foundationは、サーキュラー・エコノミーを、次の３原則で説明します。

  1. 廃棄物と汚染を排除する（Eliminate waste and pollution）。
  2. 製品と素材を、最も高い価値で循環させる（Circulate products and materials）。
  3. 自然を再生する（Regenerate nature）。

これは、「リサイクル」だけではありません。まず、そもそも廃棄物を出さない。次に、修理、再利用、再製造、シェアリングで、製品を長く使う。最後に、素材を自然に戻す。リサイクルは、最後の手段です。

赤ちゃんでもわかる一言
サーキュラー・エコノミーは、「ゴミをリサイクルする」より前に、「ゴミを出さない」「直して使う」「友だちにあげる」を考えることです。

規制の波
  • EUエコデザイン規則（ESPR）：2024年に成立。製品の環境持続性要件、デジタル製品パスポート、修理可能性、素材の透明性。
  • 修理する権利：EU指令（2024年）。家電、電子機器の修理を容易にし、部品、工具、情報へのアクセスを保証。2026年までに国内法化。
  • 欧州アクセシビリティ法（EAA）：2025年6月28日から適用。デジタル製品・サービスのアクセシビリティ。
  • AI Act：2024年8月1日発効。リスクベースの規制。禁止行為、汎用AI、高リスクAIの義務。

デザインは、「任意の善意」から「法的義務」へ移行しつつあります。これは、デザインの専門性と責任が、社会から正式に認められたことを意味します。

9-2 インクルーシブ・デザインとアクセシビリティ

ユニバーサル・デザインの起源

ロナルド・メイス（1941〜1998）は、アメリカの建築家で、自身もポリオの後遺症を持っていました。1980年代に「ユニバーサル・デザイン」という言葉を提唱し、ノースカロライナ州立大学にセンターを設立します。

ユニバーサル・デザインの７原則：

  1. 公平な使用（Equitable use）。
  2. 柔軟な使用（Flexibility in use）。
  3. 単純で直感的な使用（Simple and intuitive use）。
  4. 知覚可能な情報（Perceptible information）。
  5. エラーの許容（Tolerance for error）。
  6. 低い身体的努力（Low physical effort）。
  7. 接近と使用のためのサイズと空間（Size and space for approach and use）。
インクルーシブ・デザイン

マイクロソフトは、インクルーシブ・デザインを、次の３原則で説明します。

  1. 排除を認識する（Recognize exclusion）。
  2. 多様性から学ぶ（Learn from diversity）。
  3. 一人のために解き、多くの人に広げる（Solve for one, extend to many）。

ユニバーサル・デザインが「すべての人に同じもの」を目指すのに対し、インクルーシブ・デザインは「ミスマッチ」に注目します。人と環境のあいだの不一致を、デザインで解消する。「障がい」は、人の側にあるのではなく、人と環境の関係にあるという考え方です。

一歩深く（専門家向け）
社会モデルでは、障がいは「個人の医学的問題」ではなく、「社会の障壁」によって作られると考えます。階段は、車椅子の人を排除しますが、階段そのものが悪いのではなく、エレベーターがない環境が排除を作ります。インクルーシブ・デザインは、この環境側の障壁を設計で減らす試みです。ただし、すべての障壁をなくせるわけではなく、個別の合理的配慮も必要です。

アクセシビリティの基準
  • WCAG 2.2：2024年12月12日、W3C勧告。知覚可能、操作可能、理解可能、堅牢（POUR）の４原則。A、AA、AAAの３レベル。
  • EAA：2025年6月28日からEUで適用。銀行、交通、電子商取引、電子書籍など。
  • Section 508（アメリカ）、ADA（アメリカ）、障害者差別解消法（日本）。
  • アクセシビリティ・オーディット：自動テストと人手のテスト。スクリーンリーダー、キーボード、色覚、認知。

アクセシビリティは、「特別な人のための特別な対応」ではありません。高齢者、一時的な怪我、明るい屋外、騒がしい電車、片手での操作。誰もが、一時的に「障がい」のある状態になります。アクセシビリティは、「誰にとっても使いやすい」デザインの基盤です。

9-3 デザイン・ジャスティスと脱植民地化

デザイン・ジャスティス

サシャ・コスタンザ＝チョックは、2020年に『デザイン・ジャスティス』を出版します。デザインが、人種、ジェンダー、障がい、階級、植民地主義によって、誰を排除し、誰に負担を押しつけているかを問います。

デザイン・ジャスティスの原則（要約）：

  1. 搾取的なシステムではなく、持続可能で、共同体に責任を持つ設計。
  2. デザインのプロセスに、影響を受ける人々が参加する。
  3. デザインの便益と負担を、公平に分配する。
  4. 未来の世代、非人間の生命、生態系への影響を考慮する。
  5. デザインの知識とツールを、共同体と共有する。
  6. デザインの歴史と文脈を尊重する。
  7. デザインの専門家だけでなく、共同体の知識を重視する。
  8. デザインの結果に、説明責任を持つ。
  9. デザインのプロセスを、透明にする。
  10. デザインを、社会変革の道具として使う。
脱植民地化

Decolonising Designは、2016年に始まった、デザイン教育・実践・研究の脱植民地化を求めるプラットフォームです。

  • デザインの「普遍」は、西洋の地方的な知である。
  • デザインの歴史は、植民地主義と帝国の歴史と切り離せない。
  • デザインの教育は、非西洋の知を排除してきた。
  • デザインの実践は、先住民、有色人種、グローバル・サウスの労働を搾取してきた。
  • デザインの未来は、複数の世界（pluriverse）を尊重する必要がある。

アルトゥーロ・エスコバルは、『多元世界のためのデザイン』（2018年）で、デザインを「資本主義の道具」から「生活の再構成」へ開くことを提案します。「もう一つの世界は可能か」ではなく、「すでに多数の世界がある」という視点です。

赤ちゃんでもわかる一言
デザイン・ジャスティスは、「誰がデザインし、誰がその恩恵を受け、誰が犠牲になるか」を、公平に考えようという運動です。

参加型デザイン

参加型デザインは、1970年代のスカンジナビアから始まりました。労働者が、自分たちの職場のシステム設計に参加する権利を求めました。

  • 共同設計（co-design）：デザイナーと利用者が、一緒に設計する。
  • ユーザー・イノベーション：利用者が、自分たちの必要に合わせて製品を改良する。
  • リビングラボ：実際の環境で、利用者と一緒に試す。
  • 市民参加：都市計画、公共サービス、政策。

参加型デザインは、「デザイナーが答えを与える」モデルから、「デザイナーが対話を設計する」モデルへの転換です。ただし、参加が常に平等とは限りません。誰が参加できるか、誰が声を上げられるか、誰が決定権を持つか。権力の問題は残ります。

ジェンダーとデザイン

デザインは、ジェンダーを形づくり、ジェンダーによって形づくられてきました。

  • 教育と職業：バウハウスでは、女性はしばしば織物工房に誘導されました。グンタ・シュテルツルとアニ・アルバースは織物で、マリアンネ・ブラントは金属工房で頭角を現しましたが、建築や工業デザインの主流からは排除されがちでした。
  • 家庭のデザイン：キッチン、洗濯機、掃除機は「家事を楽にする」と言われましたが、ルース・シュワルツ・コーワン『母により多くの仕事を』（1983年）は、家事の時間が減らず、基準が上がったことを示しました。テクノロジーは、労働を消すのではなく、再配分します。
  • ジェンダー化された製品：ピンクと青、女性用と男性用のカミソリ、工具、車、医療機器。「小さくしてピンクにする（shrink it and pink it）」という批判は、女性を「別の市場」として扱うことの問題を突きます。
  • ファッション：シャネル、ヴィオネ、シャパレル。サンローランの「ル・スモーキング」（1966年）は、女性が男性用のタキシードを着ることを提案し、ジェンダーの境界を揺らしました。
  • 包摂：マタニティ、授乳、生理、更年期、介護、適応服（adaptive clothing）、サイズの多様性。身体の現実に合わないデザインは、排除を生みます。
  • 評価と権力：デニス・スコット・ブラウンは、ロバート・ヴェンチューリとの共同作業で知られますが、1991年のプリツカー賞はヴェンチューリ単独に贈られ、スコット・ブラウンは含まれませんでした。その後、彼女を含めるよう求める運動が起こりました。作者性の分配は、ジェンダーと無関係ではありません。

ジェンダーとデザインは、「女性向けの製品を作る」ことではありません。誰の身体が標準とされ、誰の労働が見えず、誰の声が作者として記録されるかという、権力の問題です。

人種・階級とデザイン

デザインは、人種や階級の不平等を、見えない形で固定することもあります。

  • 製品の標準：肌色の絆創膏、絵文字の肌色、化粧品の色展開、AIの学習データ。白い肌が「標準」とされると、それ以外の身体は「例外」になります。
  • 空間：赤線引き（redlining）、高速道路による黒人地区の分断、公共空間の「敵対的デザイン」（ベンチの仕切り、スパイク）。デザインは、誰がどこに居ていいかを決めます。
  • 階級：高級品と安価品、所有とアクセス、住宅、交通、医療。デザインの「民主化」は、しばしば市場の拡大を意味し、平等を意味しません。
  • 交差性：人種、階級、ジェンダー、障がい、移民の地位は、重なり合います。一つの軸だけを見ると、別の排除を見落とします。

一歩深く（専門家向け）
人種とテクノロジーの研究では、ルハ・ベンジャミン『Race After Technology』（2019年）、サフィヤ・ノーブル『Algorithms of Oppression』（2018年）、ジョイ・ブオラムウィニ＆ティムニット・ゲブル「Gender Shades」（2018年）などが、データ、アルゴリズム、インターフェースに埋め込まれた偏見を分析しています。デザイン・ジャスティスは、これらの分析を、製品・サービス・空間の設計に接続する実践です。

9-4 スペキュラティブ・デザインと批判的デザイン

アンソニー・ダンとフィオナ・ラビーは、批判的デザイン（critical design）とスペキュラティブ・デザイン（speculative design）を提唱します。

  • 批判的デザイン：製品の形を借りて、社会の前提を問い直す。
  • スペキュラティブ・デザイン：未来の可能性を、具体的な物語とオブジェクトで提示する。
  • デザイン・フィクション：架空の世界を、徹底的にリアルに描く。
  • 『Speculative Everything』（2013年）：未来を予測するのではなく、未来の選択肢を増やす。

スペキュラティブ・デザインは、「問題を解く」のではなく、「問題を立てる」デザインです。たとえば、遺伝子編集、監視、気候移住、AIの人格、非人間の権利。まだ存在しない製品や制度を、あえて具体的に描くことで、私たちの価値観を揺さぶります。

批判もあります。「現実の政治や経済から遊離している」「富裕層の娯楽になっている」「具体的な解決策がない」。スペキュラティブ・デザインは、現実の問題を解く力は弱いかもしれません。しかし、「未来を想像する能力」は、民主主義に不可欠です。誰が未来を想像し、誰がそれを決めるのか。この問いは、AI時代にますます重要になります。

9-5 AIとデザイン

何が変わったのか

2022年以降、生成AIが急速に普及します。

  • 画像生成：Midjourney（2022年）、DALL·E 2（2022年）、Stable Diffusion（2022年）、Adobe Firefly（2023年）。
  • テキスト生成：ChatGPT（2022年）、Claude、Geminiなど。
  • コード生成：GitHub Copilot（2021年）、Cursorなど。
  • デザインツール：Figma AI、Canva Magic Studio、Adobe Sensei。
  • 動画・音声生成：Sora（2024年）、Runway、ElevenLabs。

AIは、デザインの「制作」の一部を自動化します。アイデア出し、ムードボード、レイアウト、画像、コピー、コード、プロトタイプ。デザイナーは、「プロンプトを書く人」「生成物を選ぶ人」「システムを設計する人」になります。

AIはデザイナーを置き換えるか

短い答え：「置き換える」と「置き換えない」の二択は間違いです。

  • 置き換える仕事：定型的な画像生成、単純なレイアウト、コピーの下書き、アイコンの量産。
  • 置き換えない仕事：問題の発見、文脈の理解、利害関係者の調整、倫理的判断、説明責任、組織の変革。
  • 新しく生まれる仕事：AIの振る舞いの設計、データのキュレーション、生成物の評価、AIと人間の協働の設計、AIのバイアス監査。

歴史は、「技術が仕事を消す」という単純な物語を繰り返し否定してきました。印刷は写本師の仕事を減らしましたが、出版、編集、タイポグラフィの仕事を生みました。産業革命は手工芸を減らしましたが、工業デザイン、エンジニアリング、広告の仕事を生みました。AIも、仕事の内容を再配置します。ただし、移行の速度と公平性は、歴史とは比べ物にならないほど厳しいかもしれません。

AIのデザイン問題
  • バイアス：学習データの偏りが、差別的な結果を生む。
  • 著作権：学習データの使用、生成物の権利。
  • 労働：データ・アノテーション、クリエイターの搾取。
  • 環境：学習と推論のエネルギー、水、希少資源。
  • 均質化：同じモデル、同じスタイル、同じアイデア。
  • 説明責任：誰が、AIの決定に責任を負うのか。
  • 自律性：AIエージェントが、人間の代わりに交渉し、購入し、設計する。
  • 真正性：人間が作ったことの意味。

一歩深く（専門家向け）
AI時代のデザインは、「人間中心設計」の枠組みを拡張する必要があります。AIは、道具であると同時に、「ユーザー」でもあり（AIエージェントがサービスを使う）、「共作者」でもあり（生成AIがデザインを提案する）、「環境」でもあります（アルゴリズムが世界の見え方を決める）。人間・AI・制度・生態系を、一つのシステムとして設計する「more-than-human design」や「ontological design」の視点が重要になります。

2026年の実践
  • AIを素材として使う：生成、変異、探索。人間の判断で選ぶ。
  • AIを共同工作者として使う：アイデアの拡張、批判、テスト。
  • AIをユーザーとして設計する：エージェントが読むインターフェース、API、データ。
  • AIの倫理を設計する：透明性、説明可能性、同意、監査。
  • AIに置き換えられない価値を磨く：文脈、関係、身体、ケア、責任。

9-6 2026年のデザイン・リーダーシップ

デザインは、もはや「制作部門」ではありません。経営、政策、医療、教育、気候、AI。あらゆる領域に浸透しています。デザイン・リーダーに求められる能力は、次の通りです。

  1. 問題を発見する：与えられた課題ではなく、本当の問題を問う。
  2. システムを見る：部分最適ではなく、全体の関係を理解する。
  3. 人と対話する：多様な利害関係者を結びつける。
  4. 試作する：考えを、早く、安く、具体的にする。
  5. 測定する：成果を、定量と定性の両方で評価する。
  6. 倫理を守る：誰が傷つくか、誰が排除されるかを見る。
  7. 説明する：なぜそのデザインなのかを、言葉で語る。
  8. 手を動かす：ツールと素材を理解する。
  9. 学び続ける：技術と社会の変化に適応する。
  10. 手放す：自分が作ったものを、他者が使えるようにする。

なぜ日本だけを一章使うのか

日本は、デザイン史のなかで特異な位置を占めます。明治以降、急速に西洋の技術と制度を導入しながら、独自の職人文化、美意識、製造業の品質管理を発展させました。戦後は、ソニー、ホンダ、トヨタ、無印良品、任天堂、資生堂、イッセイミヤケなど、世界に影響を与えるブランドを生みました。

しかし、日本デザイン論は、しばしば「禅」「侘寂」「職人」といった神秘的な言葉で語られ、神話化されてきました。この章では、その神話を剥がしながら、歴史の具体物に沿って、日本のデザインを通史として描きます。

赤ちゃんでもわかる一言
日本のデザインは「禅と侘寂」だけではありません。縄文土器、着物、浮世絵、家電、ゲーム、アニメまで、驚くほど多様です。

10-1 縄文・弥生・古墳 ― 土と森のデザイン

縄文土器

日本列島では、約1万4000年前から縄文土器が作られます。世界最古級の土器の一つです。

  • 縄目：縄を押しつけた模様。装飾であると同時に、粘土の結合を強め、熱伝導を調整する機能があったと考えられます。
  • 形式の多様性：地域ごとに、深鉢、浅鉢、壺、注口土器。火焔型土器（新潟）は、過剰な装飾で知られます。
  • 土偶：女性像、動物像。祭祀、病気、出産、豊穣に関係するという説。
  • 生活：狩猟、漁労、採集。竪穴住居。貝塚。

縄文土器は、「装飾と機能の未分化」を示す典型です。美しさは、機能の外側にあるのではなく、機能の一部として作られています。

弥生文化

紀元前300年ごろから、稲作、青銅器、鉄器が伝わります。

  • 弥生土器：縄文に比べて、薄く、均質で、機能的。貯蔵、煮炊き、祭祀。
  • 青銅器：銅鏡、銅剣、銅矛、銅鐸。権力と祭祀の象徴。
  • 機織り：麻、絹。衣服の始まり。
  • 環濠集落：防御と共同体の設計。吉野ヶ里遺跡。
古墳

3〜6世紀、古墳が作られます。前方後円墳、円墳、方墳。埴輪（はにわ）は、墓の上に並べる素焼きの像です。人物、馬、家、器財。「死の空間のデザイン」であり、権力の視覚化です。

10-2 神道と平安 ― 木と紙の美

伊勢神宮 ― 20年に一度、作り直す

伊勢神宮は、日本の神社建築の原型です。内宮（皇大神宮）と外宮（豊受大神宮）。式年遷宮（しきねんせんぐう）は、20年に一度、社殿を建て替える儀式です。2013年に第62回が行われました。

  • 素材：檜、萱葺きの屋根、白い布。
  • 構造：木の柱と梁。金属の釘をあまり使わない、木の組物。
  • 様式：神明造。切妻屋根、高床、棟持柱。
  • 意味：永遠の建築は、永遠の素材ではなく、「作り直す制度」によって保たれる。これは、現代のサステナブル建築にも通じる思想です。

一歩深く（専門家向け）
式年遷宮は、単なる建て替えではありません。木材の調達、職人の継承、祭儀、地域経済、神道の時間観が一体となった制度です。一方で、巨木の枯渇、林業の衰退、費用の問題もあります。「伝統は変わらない」のではなく、「変化を制度化することで、形を保つ」のです。

平安時代 ― 着物と紙の文化

794年、平安京（京都）に遷都。国風文化が発展します。

  • 着物：直線裁ちの衣服。身分、季節、色、文様。十二単、狩衣、小袖。
  • 和紙：楮、三椏、雁皮。漉き方、模様、襖、障子、書物。
  • 漆器：蒔絵、螺鈿、沈金。漆は、保存性、光沢、修復性に優れる。
  • 屏風：空間を仕切る、絵を描く、物語を語る。
  • 庭園：寝殿造の庭。池、橋、島、植栽。
  • 書道：仮名文字。線の太さ、余白、リズム。

平安のデザインは、「平面の美」と「素材の繊細さ」に特徴があります。着物の文様、和紙の質感、漆の光沢、屏風の構図。これらは、現代の日本のグラフィックデザイン、パッケージ、インテリアにも影響を与えています。

10-3 中世 ― 禅と茶のデザイン

禅宗と空間

12〜13世紀、禅宗が中国から伝わります。禅は、建築、庭園、書、陶芸、料理に影響を与えます。

  • 書院造：床の間、書院、障子、襖。室内の軸線と格式。
  • 枯山水：石と砂で山水を表す。龍安寺（15世紀）の石庭。余白と抽象。
  • 茶室：小さな入口（にじり口）、土壁、竹、草庵。不平等を排除する空間。
  • 墨絵：雪舟、牧谿。余白と筆の勢い。
茶の湯 ― 総合芸術としてのデザイン

千利休（1522〜1591）は、わび茶を完成させます。茶の湯は、建築、庭園、陶器、花、書、料理、服装、所作を統合した、総合芸術です。

  • 楽焼：千利休の指導で、長次郎が作った手捏ねの茶碗。歪み、厚み、景色。
  • 茶室：四畳半、あるいはもっと小さい空間。床の間、炉、水屋。
  • 道具：茶碗、茶筅、茶杓、花入、香合。名物、由来、箱書き。
  • 美学：侘寂（わびさび）。不完全、儚さ、素朴、静けさ。

侘寂は、しばしば「日本の美意識の核心」とされますが、歴史的には茶の湯の美学として形成された、特定の文脈の概念です。すべての日本文化が侘寂というわけではありません。金閣寺の華麗さ、江戸の浮世絵の派手さ、現代のカワイイ文化は、侘寂とは別の美学です。

赤ちゃんでもわかる一言
侘寂は「完璧じゃないから美しい」という考え方です。でも、それは日本のすべてではなく、お茶の世界で磨かれた、一つの美意識です。

10-4 江戸 ― 浮世絵と都市のデザイン

江戸の都市計画

1603年、徳川家康が江戸に幕府を開きます。江戸は、18世紀には人口100万人を超える、世界最大級の都市になります。

  • 水路：運河、堀、川。物流と防御。
  • 防火：火除地、土蔵、瓦屋根。火事への対策。
  • 街路：格子状の町割り。大名屋敷、町人地、寺社地。
  • 上下水：井戸、水路、し尿のリサイクル。循環型都市。
  • 市場：日本橋、魚河岸。貨幣、度量衡、問屋。

江戸は、「循環型都市」として、現代のサーキュラー・エコノミーの先駆けと評価されることがあります。ただし、身分差別、疫病、貧困、火災もあり、理想化は禁物です。

浮世絵 ― 大量印刷のグラフィックデザイン

浮世絵は、江戸時代の木版画です。版元、絵師、彫師、摺師の分業で作られます。

  • 菱川師宣：浮世絵の祖。
  • 喜多川歌麿：美人画。
  • 葛飾北斎：『富嶽三十六景』（1830〜32年ごろ）。「神奈川沖浪裏」。
  • 歌川広重：『東海道五十三次』（1833〜34年）。風景版画。
  • 役者絵、相撲絵、春画、摺物。

浮世絵は、「大量生産される芸術」です。版木を彫り、和紙に摺り、色を重ねる。多色摺り（錦絵）は、1765年ごろに始まります。浮世絵は、19世紀後半にヨーロッパに渡り、ジャポニスムとして、印象派、アール・ヌーヴォー、グラフィックデザインに影響を与えます。

着物とテキスタイル

江戸時代、着物は、身分、職業、季節、地域を示す、高度なデザイン体系になります。

  • 小袖：直線裁ち。反物の幅と長さを無駄なく使う。
  • 友禅：糸目糊で防染し、色彩豊かな文様を描く。
  • 絞り：括り染め。立体感のある模様。
  • 型染：型紙で糊を置き、染める。大量生産可能。
  • 帯：帯地、帯締め、帯揚げ。結び方で意味が変わる。

着物は、「平面から身体を包む」デザインです。西洋の立体裁断とは違い、直線の布を身体に合わせて着付けます。洗い張り、仕立て直し、染め直し。修理と再利用が前提のシステムです。

10-5 明治 ― 近代化とデザイン教育

1868年、明治維新。日本は、西洋の技術、制度、デザインを急速に導入します。

  • 殖産興業：官営工場、輸出産業。生糸、茶、陶磁器、漆器。
  • 万国博覧会：1873年ウィーン、1876年フィラデルフィア、1878年パリ。日本の工芸が出品され、ジャポニスムのきっかけになる。
  • 内国勧業博覧会：1877年東京、1903年大阪。産業とデザインの展示。
  • 建築：お雇い外国人（ジョサイア・コンドルなど）。鹿鳴館（1883年）、三菱一号館（1894年）。擬洋風建築。
  • 教育：工部美術学校（1876年）、東京美術学校（1887年）、東京職工学校（1881年、後の東京高等工業学校）。図案、製図、工芸の教育。
  • 意匠：日本独自の「デザイン」概念。図案、意匠、工夫。

明治のデザインは、「西洋の技術」と「日本の工芸」の衝突と融合から始まります。輸出用の陶磁器、漆器、染織は、西洋の好みに合わせてデザインされ、同時に日本の職人技術を世界に知らせました。しかし、その多くは、日本の伝統を「エキゾチック」に消費するものでもありました。

10-6 大正・昭和戦前 ― モダンと民藝

大正モダン

1912〜1926年、大正時代。都市化、大衆文化、消費社会。

  • 百貨店：三越、白木屋、松坂屋。陳列、広告、パッケージ。
  • 大衆雑誌：『キング』（1925年）、『主婦の友』。大量印刷。
  • 映画、レコード、喫茶店、モガ（モダンガール）。
  • 建築：分離派建築会（1920年）、ル・コルビュジエの影響。
  • グラフィック：ポスター、パッケージ、広告。杉浦非水、吉田豊。
民藝 ― 名もなき職人の美

柳宗悦（1889〜1961）は、1925年に民藝（民衆的工芸）という言葉を、濱田庄司、河井寛次郎とともに作ります。1936年、東京に日本民藝館を開設。

  • 用の美：日常の道具の美しさ。使い込まれた器、素朴な布、木の家具。
  • 無名性：作者よりも、伝統と共同体を重視。
  • 手仕事：機械生産への批判。地域の素材と技術。
  • 蒐集と展示：朝鮮、沖縄、アイヌ、日本の民具。
  • 輸出：民藝運動は、日本の工芸を世界に紹介。バーナード・リーチとの交流。

民藝は、「近代への批判」であると同時に、「近代的な運動」でもありました。柳は、雑誌を編集し、展覧会を開き、博物館を作り、海外と交流しました。民藝は、ノスタルジーではなく、メディアと制度を使った運動です。

一歩深く（専門家向け）
民藝運動には、植民地主義とナショナリズムの問題があります。柳は朝鮮の工芸を高く評価しましたが、同時に「朝鮮の美は悲哀である」といったオリエンタリズム的な表現を使いました。また、民藝の「無名性」は、実際の作り手の名前を消すことにもなりました。民藝は、日本の工芸を守った一方で、職人の労働条件や地域の政治を覆い隠す側面もありました。

バウハウスと日本の近代デザイン

1920〜30年代、バウハウスは日本の建築家、デザイナーに影響を与えます。

  • 雑誌『国際建築』、『新建築』：バウハウスの紹介。
  • 建築家：前川国男、坂倉準三、丹下健三。ル・コルビュジエ、バウハウスの影響。
  • デザイン教育：東京高等工業学校、千葉大学工学部。構成教育、基礎造形。
  • プロダクト：国産の電気製品、家具、文具。機能主義の影響。
戦時下 ― デザインの動員

1930〜40年代、戦時体制のなかで、デザインは国家の動員に組み込まれます。

  • 統制経済：材料の配給、規格の統一。
  • プロパガンダ：ポスター、展覧会、映画。
  • 航空機、軍需品：機能主義の技術。
  • 「日本的なもの」：伝統の再利用。国民精神の象徴。

戦時下のデザインは、「良いデザイン」が政治と無関係ではないことを示す、重い教訓です。

10-7 戦後 ― 技術と美の奇跡

復興と工業デザイン

1945年、敗戦。日本は、GHQの占領下で、民主化、工業化、輸出振興を進めます。

  • 1946年：ソニーの前身、東京通信工業設立。
  • 1948年：本田技研工業設立。
  • 1950年：朝鮮戦争特需。日本の工業が復活。
  • 1950年代：日本インダストリアルデザイナー協会（JIDA）など、デザイン団体の組織化。
  • 1952年：GK設計（後のGKデザイン）設立。榮久庵憲司。
  • 1955年：ソニー、TR-55トランジスタラジオ。
  • 1957年：グッドデザイン賞（Gマーク）開始。通産省の「グッドデザイン商品選定制度」。
  • 1958年：ホンダ、スーパーカブ。ソニーに社名変更。

戦後の日本デザインは、「輸出のための品質」と「生活のための使いやすさ」を両立させました。Gマークは、品質とデザインの基準を作り、消費者の信頼を獲得します。

1960年代 ― オリンピックと新幹線
  • 1964年東京オリンピック：亀倉雄策のエンブレム（赤い太陽と金の五輪）、勝見勝らのピクトグラム。世界初の本格的なオリンピック・ピクトグラム体系。93カ国、5,137人の選手。
  • 1964年東海道新幹線：東京〜大阪。0系の流線型。高速鉄道のデザイン。
  • 1964年：東京モノレール、首都高速道路。
  • 1960年代：家電の普及。テレビ、洗濯機、冷蔵庫。団地、郊外。
  • 1968年：明治百年。万博の準備。

1964年は、日本のデザインが「戦後復興の象徴」から「国際的なデザイン大国」へ転換した年です。オリンピックのピクトグラムは、言語の壁を越える情報デザインの先駆けでした。

1970年大阪万博 ― 未来のショーケース

1970年、大阪で日本万国博覧会（Expo '70）が開かれます。

  • テーマ：「人類の進歩と調和」。
  • マスタープラン：丹下健三。
  • 太陽の塔：岡本太郎。高さ約70メートル。生命、祭り、未来。
  • メタボリズム：黒川紀章、菊竹清訓。成長する建築、カプセル。
  • 展示：未来都市、ロボット、宇宙、環境。
  • 来場者：約6400万人。

万博は、「デザインと国家のショーケース」でした。同時に、公害、環境破壊、消費社会への批判も強まりました。

1970年代 ― オイルショックとウォークマン
  • 1973年オイルショック：省エネ、小型車、品質管理。
  • 1979年ウォークマン：TPS-L2。ソニー。個人用音楽プレーヤー。市場調査ではなく、井深大の「飛行機で音楽を聴きたい」という個人的な欲求から生まれたという逸話。
  • 1970年代：日本の家電、自動車、時計、カメラが世界市場を席巻。
  • デザイン：機能主義、小型化、精密さ。GK、ソニー、ブラザー、ヤマハ。
1980年代 ― 無印とファッションとゲーム
  • 1980年：無印良品、西友のプライベートブランドとして誕生。40品目。「無印」「良品」。素材、機能、価格のバランス。
  • 1981年：山本耀司、コム・デ・ギャルソン（川久保玲）がパリに進出。黒、布の塊、非対称。「ヒロシマ・シック」。
  • 1983年：任天堂、ファミリーコンピュータ。
  • 1989年：ゲームボーイ。横井軍平の「枯れた技術の水平思考」。
  • 1980年代：バブル経済。デザインの華やかさ、消費、ブランド。

無印良品は、「これがいい」ではなく「これでいい」という思想で、過剰なブランドを排し、素材と機能を前面に出しました。原研哉は2000年代に、無印のアートディレクションを担当し、「白」「空」「余白」の美学を世界に広めます。

1990年代 ― 失われた十年とデジタル
  • 1991年：バブル崩壊。無印良品、ロンドンに初の海外店。
  • 1994年：ソニー・プレイステーション。
  • 1996年：ポケモン（ゲームボーイ）。
  • 1990年代：インターネット、携帯電話、iモード（1999年）。
  • デザイン：不況のなかで、コスト削減、ユニバーサル・デザイン、環境配慮。
  • 建築：安藤忠雄、SANAA、伊東豊雄。世界的な評価。
2000年代 ― グローバル化と「クールジャパン」
  • 2001年：原研哉が無印良品のアートディレクターに。無印、東証一部上場。
  • 2002年：nendo設立（佐藤オオキ）。無印、アメリカ市場へ。
  • 2003年：原研哉『デザインのデザイン』（英訳は2007年）。深澤直人、±0を設立（年号は諸説あり）。
  • 2010年代：クールジャパン政策。アニメ、マンガ、ゲーム、ファッション、食。
  • 2011年：東日本大震災。デザインの社会的役割、復興、エネルギー。
  • 2020/2021年：東京オリンピック。コロナ延期。デザイン論争（エンブレム、ロゴ、開会式）。
  • 2025年：大阪・関西万博。
2020年代 ― 高齢化、AI、サステナビリティ
  • 高齢化：人口減少、介護、医療、地域共生。ユニバーサル・デザイン、ロボット、住まい。
  • AI：生成AI、ロボティクス、自動運転。デザインの仕事の変化。
  • サステナビリティ：脱炭素、循環経済、修理、長寿命。
  • クラフト：後継者不足、職人の高齢化、海外市場。
  • 観光：オーバーツーリズム、地域資源のデザイン。
  • 防災：地震、台風、水害。レジリエントなデザイン。

赤ちゃんでもわかる一言
日本のデザインは、戦後「安くて良いものを世界に売る」ことで成長しました。今は「長く使えるもの、地域に根ざしたもの、人を包摂するもの」が問われています。

10-9 日本デザイン神話を剥がす

  1. 「日本は昔から禅と侘寂の国」：侘寂は、中世の茶の湯で形成された、特定の美学です。日本には、金閣、浮世絵、カワイイ、サイバーパンクなど、別の美学もあります。
  2. 「日本のデザインは職人技」：職人技は重要ですが、日本の強さは、職人と工学と品質管理の組織的な統合にあります。ソニー、トヨタ、任天堂は、職人だけでは説明できません。
  3. 「日本は独自のデザイン文化を持つ」：日本は、中国、朝鮮、西洋から学び、混ぜ、変形してきました。純粋な「日本」はありません。
  4. 「クールジャパンは国策の成功」：アニメ、ゲーム、ファッションは、民間の創造性と市場の産物です。国策は、それを後追いし、時に矮小化しました。
  5. 「日本のデザインは環境に優しい」：省エネ製品は多いですが、大量生産、プラスチック、原子力、輸入資源の問題もあります。聖人化は禁物です。

歴史の教訓
日本のデザインは、土器からゲームまで、驚くほど多様である。
その強さは、職人、工学、品質管理、美意識の統合にある。
しかし、それは「日本精神」ではなく、歴史的な制度と努力の産物である。
神話を捨てることで、初めて日本のデザインを正確に理解し、未来に活かせる。

モノを読む９つのステップ

デザインを見るとき、私たちはすぐに「好き」「嫌い」と言います。しかし、それだけでは、なぜそう感じるのか、誰にとって良いのかがわかりません。次の９つのステップで、対象を読んでみましょう。

  1. 描写する：色、形、素材、大きさ、重さ、文字、傷。解釈せずに、見えることを書く。
  2. 特定する：誰が、いつ、どこで、何のために作ったか。署名、刻印、ラベル、文献。
  3. 使う：実際に使ってみる。手に取る、座る、歩く、読む。身体で確かめる。
  4. 構造を見る：どう組み立てられているか。接合、素材、部品、修理可能性。
  5. 機能を見る：何を可能にし、何を不可能にするか。使いやすさ、誤用、危険。
  6. 意味を見る：何を象徴しているか。色、形、素材、文脈、広告、展示。
  7. 生産を見る：誰が、どのように、どのくらいの労働とエネルギーで作ったか。
  8. 後日談を見る：使われた後、修理されたか、捨てられたか、再利用されたか、博物館に入ったか。
  9. 比較する：同じ時代の他の対象、他の地域の似た対象、前後の時代と比べる。

この９ステップは、美術品にも、スマホにも、椅子にも、都市にも使えます。大切なのは、「好き嫌い」の前に、観察と文脈を置くことです。

デザインを支える12の原理

1. アフォーダンス（Affordance）

物が提供する行為の可能性。椅子は「座る」、取っ手は「引く」、ボタンは「押す」をアフォードします。ただし、アフォーダンスは文化と身体によって変わります。

2. シグニファイア（Signifier）

行為を促す手がかり。矢印、ラベル、色、形。アフォーダンスが「可能性」なら、シグニファイアは「合図」です。

3. マッピング（Mapping）

操作と結果の対応。コンロのつまみと火口の位置、ゲームのコントローラーと画面の動き。自然な対応は、学習を減らします。

4. フィードバック（Feedback）

行為の結果を知らせること。音、光、振動、メッセージ。フィードバックが遅いと、人は不安になります。

5. 制約（Constraint）

できることを制限する。間違った使い方を防ぐ。物理的な制約、文化的な制約、論理的な制約。

6. 概念モデル（Conceptual Model）

ユーザーが頭のなかで作る、仕組みの理解。ファイル、フォルダ、ゴミ箱。良い概念モデルは、説明なしで使える。

7. 階層（Hierarchy）

重要度の順序。大きさ、色、位置、余白。何を最初に見せ、何を後回しにするか。

8. グリッド（Grid）

配置の基準。列、行、余白、比率。新聞、雑誌、ウェブ、都市。グリッドは、秩序と柔軟性を両立させます。

9. コントラスト（Contrast）

違いを作る。明暗、色、大きさ、書体、素材。コントラストは、焦点とリズムを作ります。

10. リズム（Rhythm）

繰り返しと変化。模様、柱、窓、文字、動き。リズムは、時間と空間に心地よさを作ります。

11. エコノミー（Economy）

最小の手段で最大の効果。材料、工程、言葉、動き。ただし、経済性は、耐久性、修理性、安全性とバランスが必要です。

12. 修復（Repair）

壊れたときに直せること。部品、工具、情報、設計。修復可能性は、持続性と愛着の基盤です。

一歩深く（専門家向け）
これらの原理は、ゲシュタルト心理学、認知心理学、人間工学、記号論、建築理論から来ています。ただし、原理は「法則」ではありません。文化、身体、状況によって効果は変わります。たとえば、赤が「危険」を意味する文化もあれば、「幸運」を意味する文化もあります。原理を普遍的なレシピとして使うのではなく、仮説として使い、テストすることが重要です。

色彩 ― 見えることの設計

色彩は、単なる「好み」ではありません。光、素材、文化、身体、規格が交差する、デザインの基盤です。

  • 三属性：色相（hue）、明度（value）、彩度（saturation）。色は、この三次元の空間のなかの位置として捉えられます。
  • 混色：光の加法混色（RGB）、絵の具の減法混色（CMY）、印刷のCMYK。画面と印刷では、色の出方が違います。
  • 表色系：マンセル、NCS、Pantone。Pantoneは、印刷・素材・ブランドの色を共有するための仕組みです。
  • 対比：同時対比、明暗対比、補色対比。同じ色でも、隣の色で違って見えます。
  • 文化：赤は、危険、愛、幸運、革命。白は、純粋、喪、空白。意味は、文化と文脈で変わります。
  • アクセシビリティ：WCAG 2.2は、通常の文字で4.5:1、大きな文字で3:1以上のコントラストを求めます（AA）。色だけで情報を伝えてはいけません。
  • 素材：顔料、染料、釉薬、アルマイト、塗装。素材と光で、色は変化します。

タイポグラフィ ― 文字の身体

タイポグラフィは、文字を「読める」「伝わる」「美しい」ものにする技術です。

  • 解剖：ベースライン、xハイト、アセンダー、ディセンダー、カウンター、ステム、セリフ。
  • 分類：ヒューマニスト、トランジショナル、モダン、スラブセリフ、サンセリフ（グロテスク、ジオメトリック、ヒューマニスト）、スクリプト、ディスプレイ。
  • 組版：カーニング、トラッキング、行間（リーディング）、行長（メジャー）、階層、孤立行・分離行。
  • 日本語：和文と欧文の混植、禁則処理、約物、縦組み、フォントライセンス。日本語の文字は、欧文より複雑で、行間と余白の設計が重要です。
  • アクセシビリティ：文字サイズ、コントラスト、行間、読みやすさ。ディスレクシア向けフォントは、万能ではありません。
  • 可変フォント：一つのファイルで、太さ、幅、光学サイズを連続的に変えられる。デジタルならではの表現。

グリッド ― 秩序の骨格

グリッドは、情報を配置するための見えない骨格です。

  • 基本：マージン、カラム、ガター、ベースライン。
  • 種類：マニュスクリプト、カラム、モジュラー、ベースライン。
  • スイス・スタイル：非対称グリッド、サンセリフ、左揃え。ミュラー＝ブロックマンの『グリッド・システム』（1981年）。
  • ウェブ：12カラム、CSS Grid、レスポンシブ。画面サイズに応じて、グリッドを組み替える。
  • イデオロギー：グリッドは、秩序、効率、平等を作りますが、同時に、はみ出すもの、混沌、地域の多様性を排除することもあります。

赤ちゃんでもわかる一言
色は「気持ち」、文字は「声」、グリッドは「骨格」です。この三つが揃うと、情報は、読みやすく、覚えやすく、美しくなります。

第13章 通説vs.証拠 ― 20の神話を壊す

5,555 CHARACTERS約 11 分

なぜ神話を壊すのか

デザイン史には、便利な「神話」がたくさんあります。神話は、複雑な歴史をわかりやすくし、共感を生みます。しかし、神話はしばしば、権力を隠し、労働を消し、多様性を削ります。この章では、よく聞く20の通説を、証拠と照らし合わせます。

判定は、次の3つです。

  • ○：ほぼ正しい。ただし、ニュアンスが必要。
  • △：半分正しい。条件や文脈による。
  • ×：誤り、または誤解を招く。

注意
この章の判定は、本書の調査範囲におけるものです。歴史には異説があり、新しい研究で変わる可能性があります。詳細は付録Aのファクトチェック記録を見てください。

神話1：「バウハウスは一つの様式だった」

判定：×

バウハウスは、1919〜1933年の学校であり、一つの統一様式ではありません。ヴァイマール期（表現主義、手仕事）、デッサウ期（機能主義、工業生産）、ベルリン期（建築、美学）で、思想も作風も変わります。校長も、グロピウス、マイヤー、ミースで大きく異なります。

「バウハウス様式」という言葉は、後世のデザイン史・マーケティングが作った便宜的なラベルです。白い箱、サンセリフ、鋼管椅子は、バウハウスの一部であって、全体ではありません。

神話2：「バウハウスは世界最初のデザイン学校だった」

判定：×

バウハウス以前にも、美術学校、工芸学校、建築学校は存在しました。同時代には、ロシアのヴフテマス（1920年設立）があり、バウハウスと似た理念（芸術と技術の統合、基礎教育、工房）を持っていました。

バウハウスの重要性は、「最初」であることではなく、教育モデル、出版物、亡命者ネットワークを通じて、世界中に影響を広げたことです。

神話3：「形は機能に従う（Form follows function）はバウハウスのスローガンだった」

判定：×

「形は機能に従う」は、アメリカの建築家ルイス・サリヴァンが1896年の論文で書いた言葉です。正確には「form ever follows function（形は常に機能に従う）」。

バウハウスは、この言葉をそのままスローガンにしたわけではありません。バウハウスの思想は、機能、素材、構造、社会の関係を、もっと複雑に扱いました。また、「機能」は、機械的な用途だけでなく、心理的・社会的な機能も含みます。

神話4：「ロースはすべての装飾を否定した」

判定：△

アドルフ・ロースは、『装飾と犯罪』（1908年講演、1910年再講演、1913年出版）で、日用品の装飾を激しく批判しました。しかし、彼は無装飾の機能主義者ではありませんでした。大理石、木、真鍮などの素材の質を重視し、内部空間には豊かな素材を使いました。

また、このテキストには、装飾を「未開」「犯罪者」「退化」と結びつける人種主義的なレトリックがあります。今日読むときは、美学的主張と偏見を分けて評価する必要があります。

神話5：「モリスは機械を全面否定した」

判定：△

ウィリアム・モリスは、機械による分業と大量生産を批判しましたが、すべての機械を否定したわけではありません。彼の会社は、一部の工程で機械を使い、手仕事と機械を組み合わせました。彼の批判の中心は、資本主義的な分業が、労働者を「手」にし、仕事の喜びを奪うことでした。

また、モリスの手作り品は高価で、富裕層しか買えませんでした。「みんなのための芸術」という理想と、実際の市場の矛盾は、アーツ・アンド・クラフツ運動の根本的な問題です。

神話6：「クリスタル・パレスは最初の鉄とガラスの建築だった」

判定：×

クリスタル・パレス（1851年）は、鉄とガラスの建築の集大成であり、最初ではありません。18世紀には、温室、市場、駅舎、橋などで、鉄骨とガラスの構造が使われていました。パクストン自身も、温室の設計者でした。

クリスタル・パレスの革新性は、素材の発明ではなく、プレハブ式の大量生産、短期間の建設、巨大なスケール、博覧会というメディアにあります。

神話7：「最初の工業デザイナーは、ジョセフ・クロード・シネルだ」

判定：△

「工業デザイン」という言葉の起源は、はっきりしません。シネルが1919年に使ったという説もありますが、本人は否定しています。1840年の『The Art-Union』に最初の使用例があるという説もあります。

職業としては、クリストファー・ドレッサー（1834〜1904）のように、複数のメーカーに図案を提供した独立デザイナーが、19世紀後半に存在しました。「最初の一人」を決めることより、職業が徐々に形成された過程を見るほうが重要です。

神話8：「ラムズの10原則は、時代を超えた永遠の真理だ」

判定：△

ラムズの10原則は、1970年代末に、消費社会の「形、色、音の耐え難い混乱」への危機感から生まれました。歴史的・文化的に規定された思想です。

特に「控えめ」「正直」「長持ち」「環境に優しい」は、今日のサステナブルデザインにも通じます。一方で、白と灰色のミニマリズムが、すべての文化や用途に適するわけではありません。10原則は、デザイナーの倫理の宣言として読むのが正確です。

神話9：「アップルがGUIとスマートフォンを発明した」

判定：×

GUIは、ゼロックス・パロアルト研究所（Alto、1973年）やダグラス・エンゲルバート（1968年）の研究に起源があります。スマートフォンも、PDA、携帯電話、タッチスクリーン、iPodなど、多数の先行技術の融合です。

アップルの貢献は、技術を、使いやすく、美しく、一つの体験に統合したことです。発明と統合は、別の仕事です。両方を区別して評価する必要があります。

神話10：「デザイン思考はIDEOが発明した」

判定：×

デザイン思考のルーツは、ハーバート・サイモン『人工物の科学』（1969年）、リッテルとウェバーの「厄介な問題」（1973年）、ドナルド・ショーンの「省察的実践」（1983年）、リチャード・ブキャナンの論文（1992年）などにあります。

IDEO（1991年）とスタンフォード d.school（2005年）は、デザイン思考を普及させ、ビジネスの言語に翻訳しました。発明と普及は、別の仕事です。

神話11：「ユニバーサル・デザインは、すべての人に同じものを提供することだ」

判定：×

ユニバーサル・デザインは、できるだけ多くの人が使えるように設計する思想ですが、「一つのサイズですべてに合う（one size fits all）」ではありません。7つの原則は、公平性、柔軟性、単純さ、知覚可能性、エラー許容、低負荷、空間の確保を求めます。

インクルーシブ・デザインは、さらに「ミスマッチ」に注目します。人と環境の不一致を、設計で減らす。すべての障壁をなくせるわけではなく、個別の合理的配慮も必要です。

神話12：「サステナブル・デザインとは、リサイクルすることだ」

判定：×

サーキュラー・エコノミーは、リサイクルより前に、廃棄物を出さない、長く使う、修理する、再利用する、再製造することを優先します。リサイクルは、最後の手段です。

また、サステナビリティは、環境だけでなく、社会（労働、人権、地域）と経済（長期的な価値）を含みます。「環境に優しい」製品が、労働者を搾取していたら、サステナブルとは言えません。

神話13：「日本デザインは、禅と侘寂のミニマリズムだ」

判定：×

侘寂は、中世の茶の湯で形成された、特定の美学です。日本には、金閣寺の華麗さ、浮世絵の派手さ、カワイイ文化、サイバーパンク、過剰なパッケージなど、多様な美学があります。

「日本＝禅」というイメージは、欧米のオリエンタリズムと、日本のナショナリズムが作り上げたものです。日本のデザインを理解するには、職人、工学、品質管理、マスメディア、消費文化の歴史を見る必要があります。

神話14：「民藝は、近代に抗する伝統主義だった」

判定：△

民藝は、機械生産と資本主義への批判を含みますが、同時に近代的な運動でした。柳宗悦は、雑誌を編集し、展覧会を開き、博物館を作り、海外と交流しました。民藝は、メディア、制度、市場を使った運動です。

また、民藝の「無名性」は、職人の名前を消し、労働条件を覆い隠す側面もありました。柳の朝鮮観には、オリエンタリズム的な表現もあります。民藝は、単純な伝統主義ではなく、近代の矛盾を抱えた運動です。

神話15：「アール・デコは、単なる装飾様式だ」

判定：△

アール・デコは、1920〜30年代の装飾様式ですが、単なる表面の装飾ではありません。機械時代の素材（金属、ガラス、漆）、大量生産、消費文化、帝国の交易、ジャズ・エイジの文化と結びついていました。

クライスラー・ビル、客船、映画館、香水瓶。アール・デコは、近代の速度と豪華さを、視覚化する装置でした。同時に、植民地のモチーフを消費する「エキゾチシズム」の問題もあります。

神話16：「バウハウスは政治的に中立だった」

判定：×

グロピウスは、バウハウスを「非政治的」と主張しましたが、学校は政治的に激しく争われました。ヴァイマール期には保守派から攻撃され、デッサウ期にはナチスが閉校を迫り、マイヤーは社会主義的な立場で解任されました。

バウハウスの閉校は、ナチスの文化的抑圧と無関係ではありません。同時に、校側が最終的に解散を決めたという複雑さもあります。「政治的中立」は、当時の建前であり、現実ではありませんでした。

神話17：「テルアビブのホワイト・シティは、純粋なバウハウスだ」

判定：△

テルアビブには、1930年代にユダヤ人建築家たちが、バウハウス/インターナショナル・スタイルの影響を受けた建築を多数建てました。約4000棟とも言われ、2003年にUNESCO世界遺産に登録されています。

しかし、それは「純粋なバウハウス」ではありません。気候、風土、文化、予算に合わせた現地適応があり、建築家も多様です。「バウハウス」は、便利なラベルですが、実際は国際様式の地方変種です。

神話18：「ユーザーは常に正しい」

判定：×

ユーザーは、多様で、矛盾し、変化します。ユーザーの言葉をそのまま聞くだけでは、本当のニーズはわかりません。観察、対話、試作、検証が必要です。

また、ユーザー中心設計は、しばしば「現状の欲望」に最適化し、社会全体の利益や、未来の世代、非人間の生命を無視します。「ユーザーは常に正しい」は、マーケティングの標語であり、デザインの原理ではありません。

神話19：「AIはデザイナーを置き換える」

判定：×

AIは、デザインの一部のタスクを自動化します。画像生成、レイアウト、コピー、コード、プロトタイプ。しかし、問題の発見、文脈の理解、利害関係者の調整、倫理的判断、説明責任は、人間に残ります。

歴史を見ても、技術は仕事を「消す」のではなく、「再配置」してきました。ただし、移行の速度と公平性は、深刻な問題です。「置き換える/置き換えない」の二択ではなく、どのタスクが、誰によって、どの条件で再配置されるかを見る必要があります。

神話20：「デザインは、ものを美しくすることだ」

判定：×

デザインは、美しさを含みますが、それだけではありません。意図を、制約のなかで、他者のために形にすることです。製品、システム、サービス、体験、組織、政策。美しさは、機能、使いやすさ、意味、持続性、正義と並ぶ、一つの評価軸です。

「美しくする」だけなら、デザインは装飾の技術になります。しかし、デザインは、世界の一部を、別のあり方にする技術です。だから、倫理と責任が必要なのです。

第15章 デザインの未来 ― 何が残り、何が変わるのか

PLATES IN THIS CHAPTERPL.12 AI

10の提案

1. モノから、関係へ

デザインの対象は、製品から、サービス、システム、制度、関係へ広がります。良い椅子を作るだけでなく、椅子が使われる場、修理する仕組み、廃棄された後の循環を設計する。

2. 人間中心から、生命中心へ

人間だけがユーザーではありません。動物、植物、生態系、未来の世代、AIエージェントも、デザインの影響を受けます。「人間のため」だけでは、気候危機を止められません。

3. 普遍から、多元世界へ

グローバルな標準は必要ですが、地域の文化、主権、知恵を無視してはいけません。複数の世界が共存する「pluriverse」の視点が、これからのデザインの基盤になります。

4. 収奪から、再生へ

素材を採り、使い、捨てる線形経済から、再生する循環経済へ。デザインは、廃棄物を出さない、自然を回復する、地域の生態系を支える方向に進みます。

5. 画面から、空間と環境へ

スマートフォンの画面は、まだ重要ですが、デザインの場は、AR/VR、音声、センサー、都市、建築、身体へ広がります。インターフェースは、画面から世界へ溶け出します。

6. 作者から、管理者へ

デザイナーは、作者であるだけでなく、システムの管理者、編集者、キュレーター、仲介者になります。AIが生成し、コミュニティが参加し、規制が形を決める。作者性は、分散します。

7. 解決から、問いへ

デザインは、問題を解くだけでなく、問題を立てます。何が問題か、誰にとって問題か、なぜ今問題か。スペキュラティブ・デザインと批判的デザインは、この問いの技術です。

8. イノベーションから、メンテナンスへ

新しいものを作るだけでなく、既存のものを維持し、修理し、改善する。インフラ、建築、公共サービス、コミュニティ。「壊れないこと」も、デザインの仕事です。

9. デザイン思考から、デザイン判断へ

プロセスや付箋ではなく、「何が良いか」を判断する力が重要になります。美的判断、倫理的判断、政治的判断、技術的判断。デザインは、総合的な判断の学問です。

10. 「良いデザイン」から、「正しいデザイン」へ

「良い」は、誰にとって良いのか。デザイン・ジャスティスは、便益と負担の公平な分配、参加、説明責任を求めます。美しさと正義は、対立するのではなく、両立すべき目標です。

何が残るのか

技術が変わっても、次のものは残ります。

  • 身体：人間は、身体で世界を知覚し、操作します。身体の大きさ、力、感覚、老化。デザインは、身体から逃れられません。
  • 文脈：文化、歴史、地域、制度。同じ製品でも、使われる場によって意味が変わります。
  • 関係：人と人、人と物、人と自然。デザインは、関係の編集です。
  • 時間：使う、慣れる、壊れる、直す、捨てる、思い出す。デザインは、時間のなかで変化します。
  • 責任：誰が決め、誰が責任を負うか。AIが生成しても、責任は人間に残ります。
  • 希望：デザインは、今の世界を別の形にする可能性です。希望は、根拠のない楽観ではなく、具体的な制作のなかにあります。

デザイナーの誓い

私は、デザインが人を傷つける力を持つことを知っています。
だから、誰がこのデザインを使い、誰が使えないかを、最初に考えます。
私は、美しさを追求しますが、それは誰かを排除する美しさではありません。
私は、作る前に、問います。なぜ作るのか。誰のために作るのか。作らない選択はないか。
私は、壊れたものを直し、長く使えるようにし、次の世代に手渡します。
私は、自分の専門外の人から学び、自分の無知を認めます。
私は、作ったものに対して、最後まで責任を負います。
これが、私のデザインの誓いです。

最後に ― デザインは、世界の編集である

デザインの歴史をたどると、人間はいつも、「今ある世界を、別の形にしたい」という願いから、何かを作ってきました。土器は食べ物を保存し、文字は記憶を保存し、印刷は知識を広げ、工場は物を増やし、画面は距離を縮めました。そのたびに、新しい可能性と、新しい問題が生まれました。

デザインは、世界を「創造」するのではなく、「編集」します。素材を選び、関係を組み替え、意味を付け替える。その編集の力は、使い方次第で、解放にも抑圧にもなります。

だから、デザインを学ぶことは、「どんな世界に住みたいか」を考えることです。それは、技術者だけの仕事ではありません。使う人、作る人、直す人、捨てる人、未来の世代。すべての人が、デザインの当事者です。

歴史の教訓
デザインの未来は、予測できない。
しかし、方向は選べる。
より包摂的に、より再生可能に、より公正に、より人間以外のものにも優しく。
その選択は、今日の、小さなデザインの決断のなかにある。

修正した主な誤り

  1. 「メンフィスは1981年結成」
    → 1980年に活動開始、1981年に最初の展覧会。 「結成」 と 「初展」 を分ける必要がありました。

  2. 「d.schoolは2003年設立」
    → 2005年設立。2003年は前身の授業。 「授業の開始」 と 「学校の設立」 を混同していました。

  3. 「東京1964のピクトグラムは亀倉雄策」
    → ピクトグラムは勝見勝らのチーム。亀倉はエンブレムとポスター。二人の役割を分けました。

  4. 「バウハウスはナチスが閉校した」
    → ナチスの圧力とゲシュタポの介入のなかで、校側が解散を決定。 「一方的に閉鎖」 ではなく、 「圧力下の解散」 という複雑さがあります。

  5. 「無印良品のロンドン店は2001年」
    → 1991年。2001年は東証一部上場。年号を取り違えていました。

  6. 「原研哉『デザインのデザイン』は2007年」
    → 日本語版は2003年、英訳版が2007年。版の違いを区別しました。

  7. 「深澤直人の±0は2008年設立」
    → 2003年ごろ。年号は資料によって幅があるため、 「2003年ごろ」 としました。

  8. 「バウハウス宣言の引用」
    → 逐語訳ではなく要旨。引用符を外し、 「趣旨」 と明記しました。

  9. 「バウハウスは23年続いた」
    → 1919〜1933年は14年。単純な計算違いを修正しました。

  10. 「モヘンジョ・ダロは約2600年前」
    → 紀元前2500年ごろで、約4500年前。年表の「紀元前」と「年前」を混同していました。

  11. 「ノーマン『誰のためのデザイン？』は1993年」
    → 原著は1988年。年表の年号を修正しました。

  12. 「東京高等工業学校は1881年」
    → 1881年は東京職工学校。1901年に東京高等工業学校へ改称。名称と年号を分けました。

  13. 「ブルーノ・プロイヤー」
    → マルセル・ブロイヤー。名前を修正しました。
